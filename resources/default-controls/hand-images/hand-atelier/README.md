## 资源契约

- 画布：400×400，透明背景 PNG。
- 旋转中心：`(200, 200)`，即图片正中心。
- 朝向：针尖朝正上方（12 点方向），尾部朝下。
- 接入方式：图片中心对齐表盘圆心，按当前时间旋转。
  - 时针 `(hour % 12 + minute / 60) × 30°`
  - 分针 `(minute + second / 60) × 6°`
  - 秒针 `second × 6°`
- 轴帽 `*-cap.png` 常驻圆心，不旋转。
- AOD 建议：隐藏秒针，保留时针 / 分针 / 轴帽并降低亮度。

`manifest.json` 记录每套的名称、说明与资源路径，格式 `gfc-hand-image-pack` / `formatVersion 1`。

## 预览

- `showcase.html`：深色表盘实时预览，可改时间查看任意时刻的叠戴效果。
- `showcase.png`：整页预览图。

所有表针为原创多边形绘制，带高光、阴影、镂空与夜光细节，未使用第三方表针图像，无版权资源依赖。
