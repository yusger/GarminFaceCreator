# 授权字体素材

字体身份见catalog.json；每份TTF随同名-LICENSE.txt完整许可发布。Rajdhani Light/Bold来自[Google Fonts](https://github.com/google/fonts/tree/main/ofl/rajdhani)，原作者Indian Type Foundry，许可SIL OFL1.1。[provenance](rajdhani-provenance.json)保存下载时的固定提交、来源URL和SHA-256；原始字体字节没有修改。

编辑器生成的固定像素字形使用GFC内部字体名并保留完整原始许可。细线小字号的可读性、暗色抗锯齿和原生截图必须另验，不能因为文件已加入就宣称所有字号和设备均通过。
