# Linux SDK 模拟器隔离原型

实验性验证工具，尚不是网站可用的验证服务。独立 Ubuntu 22.04 GUI 依赖镜像，不能替换现有编译镜像。SDK和设备缓存只读挂载；输入只挂一个已编译PRG，输出为独立任务目录，不挂开发者密钥、后端配置或全部构建目录。

运行须指定实际编译目标DEVICE，限制CPU/内存/PID/总超时、无外部网络、无新增权限及只读根目录，HOME和/tmp用受限tmpfs。示例编排由实验记录给出；勿将主站Docker socket暴露给用户或网页。run.sh仅产生桌面截图和日志，尚不构成原生绘制成功、固定数据、AOD切换、盘面裁切或可下载服务的验收。

后续只有实际跑通GUI、PRG加载、异常识别和绘制完成条件，再做受限队列/产物API。桌面截图与浏览器截图、真机性能/功耗结论分开。
