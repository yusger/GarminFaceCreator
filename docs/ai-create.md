# AI创建表盘

项目页的“AI创建表盘”位于空白画布旁：选择项目名称、系列/型号/尺寸，再选择数字/指针/混合模式、秒数、日期和子数据；最后选择已有模型，添加参考图与提示词，点击“生成表盘项目”。

这一步浏览器直接调用配置的兼容模型接口，只返回可编辑设计，不生成Monkey C、不调用编译服务、不自动重试。参考图需要模型支持图片理解。成功后先检查预览，点击“采用设计并编辑”保存独立本地项目；也可以重新生成或先下载设计备份。

可以继续拖动、修改数据、颜色、字号和图片；这些编辑不调用模型。满意后再点击原有“AI生成代码”→“生成完整工程”，审阅并应用，再编译下载PRG。没有特殊原生效果说明时也可用本地生成。设计改动将工程标记过期，旧代码保留历史，不自动重新生成。

参考图最多3张、原文件每张4MB，浏览器转换PNG并将最长边限制为1600；分风格参考、布局参考、实际素材。风格/布局图不自动进入运行资源；只有实际素材被模型明确引用后才随项目保存，并在后续编译时发送到编译服务。首版没有生图接口，不声称能凭空生成照片或人物位图。向导关闭后原始参考图不保留，项目保存使用过的素材及参考用途摘要。

图层属性新增可选“原生效果说明”，随导出、导入与设计快照保留。它在后续AI生成工程时与当前控件一起发送；网页仍显示基础布局，不执行文本或脚本。本地生成遇到非空说明会明确提示不支持，避免漏掉设计要求。初始designBrief仅记录原始需求，当前图层优先，不允许用旧需求覆盖手动修改。

基础设计协议为gfc-ai-design-v1，使用454逻辑坐标及真实目标设备元数据；模型不分配项目身份、不返回代码、网络资源或任意字段。程序校验字段、绑定、时间风格、选中数据、AOD和圆屏边界，校验失败不保存项目。错误响应可下载排查；取消请求忽略迟到结果；保存失败保留有效设计供重试或备份。未使用的特殊能力不会悄悄转为伪数据。

当前开放24h整数秒，组合日期及内部现有数据目录；不开放12h/AMPM、农历、节气、节假日、通知数和平滑扫秒。meter只支持步数/电量，ring另支持秒/心率/静态。设备API和缓存可用性仍需检查；实际字体和特殊原生效果通过模拟器/真机核对。

实现使用内部schema23，旧项目迁移保留身份及图层；外部接入规范formatVersion仍为1，不因AI入口扩大字段集合。详见[基础规范v1.1](standards/watchface-basic-spec.md)和[设计包接入规范v1.2](standards/watchface-package-standard.md)。

设计请求的数据单位来自原生适配器：当前距离km、海拔ft、天气温度°C、风速m/s；模型不得只换单位文字伪装数值转换。
