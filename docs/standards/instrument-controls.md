# 基础仪表复合控件

素材库新增活动多环、天气温度信息带、电量仪表、指针副盘，包放在resources/default-controls/widgets。使用已有formatVersion=1中已声明的ring/hand/date等类型，不放宽外部发布profile或增加可执行扩展。适配器将含这些类型的实例保存为内部Compound v2，旧四款继续v1，默认选择及顺序保留。每包含许可、适配说明、亮屏/AOD SVG示意和正常/零/缺失/最大/AOD用例。

活动环默认步数10000/心率180/电量100；目标是样式参数，不是个人或医学目标。天气带显示缓存温度与日期，单位用ASCII“ C”（摄氏）符合当前原生字体限制，不虚构湿度/风速/降雨。电量仪表组合进度环、数字和分段条。指针副盘用设备时钟驱动时/分针与静态刻度；缺失传感器不隐藏静态钟面。

插入后各自一个对象，内部部件可启用/隐藏、改色，复制引用独立、等比缩放；高级内部编辑增加环源/目标/分段或连续样式及指针长度。需要任意结构可显式拆解，AI仍只可通过公开部件/参数接口操作。AOD按子层开关、暗轨道、无秒动语义生成；示意图不等于原生固定数据截图或真机功耗验收。Rider未加入默认库。
