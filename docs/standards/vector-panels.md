# 简单异形面板与几何预算

Schema44/basic54扩展polygon为单个简单闭合轮廓：3–32个0..1归一化顶点，支持凹形；轮廓不重复末点。禁止孔洞、自交、接触/重叠边、重复点、相邻共线退化边和近零面积。32点上限不因Garmin最多64点而自动放宽。

网页仍是一个可拖动缩放、旋转、填充/描边/AOD对象。生成时用有界耳切检查轮廓可分解性（最多n-2/30三角形）；原生实际一次fillPolygon填充完整轮廓，并关闭填充期间的隐式描边，再只描原始外轮廓。凸形保持原绘制，避免重建默认参考外观。Garmin fillPolygon每调用最多64点，本实现每次最多32点。生成前验证，不把无法表达的孔洞静默填平。

AI创建/对话/工程DTO采用相同轮廓校验；失败原子回滚。坐标随454设计到目标设备缩放和像素取整。初版逐三角形填充的原生截图出现内部亮边，basic55改为单次完整填充；透明与细描边仍需原生像素对照，数学分解或SDK编译不代表视觉通过。

旧custom-widget/reference-release v2的凸几何合同冻结，校验器显式调用validConvexPolygon，不因编辑器升级自动接受凹形。新增theme-project-v1为独立外部契约；组件样式实例见下文当前交付。贝塞尔、SVG可编辑转换、虚线及路径分布继续不开放。

依据：[Garmin Graphics.Dc.fillPolygon](https://developer.garmin.com/connect-iq/api-docs/Toybox/Graphics/Dc.html#fillPolygon-instance_function)。SDK两尺寸、网页交互、轮廓/面积/预算和原生视觉分别验收。

## 阶段G路径能力评估与当前边界

- 简单凹多边形已交付：最多32点、单轮廓、无孔洞和交叉；原生单次填充及外轮廓已有两尺寸截图证据，不能退回三角形逐个填充造成亮边。
- 圆/圆角采样继续使用`primitiveSampling`：目标弦误差0.5物理像素，圆12–64段、圆角每角1–15段；超预算明确诊断。该误差仅含采样，不含原生像素量化和抗锯齿。
- 贝塞尔自由路径：本轮评估后不开放。当前没有路径拓扑/控制点存储、浏览器与原生同源自适应细分或长度预算；不能只加SVG path让预览先行。未来需要曲线误差≤0.5px、有界分段、明确闭合/孔洞限制及原生对照。
- 虚线/沿路径分布：当前没有线型或路径参数控件。本轮不把多根线或多张静态图伪称为原生虚线/路径控件；后续须定义dash phase、端帽、路径弧长、总段数及缩放规则，并与单轮廓32点限制分开。
- 自定义刻度：已有圆环刻度与圆周复制可组成固定刻度设计，属于可编辑图层组合；任意路径刻度、变宽刻度及自动沿曲线排布不支持。保留200总对象预算，含复合内部对象。
- SVG：一般本地图片导入仅PNG/JPEG/WebP，未开放通用SVG可编辑转换。现有受控SVG素材/图标的栅格资源流程是静态图片，不变成可编辑路径；接受受控素材不等于接受任意SVG、脚本、滤镜或外部引用。界面导入应继续明确显示实际格式限制，不静默降级。
- [组件主样式](component-styles.md)已实现受限外观实例：稳定映射、版本发布、覆盖、脱离和撤销；字体/素材/结构替换和父对象整体旋转不在此实例协议内。

以上是本轮评估结论及明确不开放范围，不是未来路径功能的完成声明。后续如开放新路径种类，需另行迁移、公开契约和真实原生验证。
