# 主题颜色与字体角色（Schema49）

角色使用明确身份和图层引用，不通过同色、邻接或显示名称猜测关系。公共框架与每个主题分别定义；一个字体成员只属于一个角色，不能跨主题。修改尊重锁定对象并作为完整事务提交。

## 字体

项目fontRoles最多24项，每项id/name/themeId（公共项省略）/fontId/layerIds。fontId只能取批准的系统、资源库、本地或BMF身份；成员为独立文字、时间、日期、数据或图表，字体适用范围与原有选择器一致。角色选择的实际字体已物化到图层并验证一致；不创建任意字体路径。资源许可、缺字及BMF像素限制继续适用。

角色更新一组成员的字体，保留各自位置、框和普通字体字号；选择BMF时按其固定物理字号设置size/aodSize。单独更换字体或字重会明确解除该成员关联，移动或普通字号调整不会解除。也可在角色面板显式解除单个成员或整个角色，保留当前外观。删除图层同步清理引用。

字体角色是编辑器设计能力，更改后重新生成工程；不是手表运行时字体设置。项目保存、复制/导入、设计快照和撤销包含角色定义。共享主设计可修改角色，设备独立字体覆盖保留；导出单设备副本时，字体已不同于主角色的成员解除该副本中的关联。

主题定义更新替换字体与角色定义，手工设计的解除记录不作为controlValues持久设置兼容项保留；更新预检明确替换设计范围，可撤销。设备字体覆盖仍按多设备定义升级规则保留。不要把设计更新当作跨PRG设置迁移。

## 颜色

现有颜色配置可声明semantic：primary（主色）、accent（强调色）、track（暗轨）、text（文字）、warning（警告）、danger（危险）；不声明表示固定颜色。颜色配置的targets继续显式指向color或已有thresholdRules.N.color；分类本身不创建传感器规则，也不把PNG变成可重着色图片。

颜色和阈值色分别解析。数据槽先选择来源及对应阈值，再应用颜色：原来源保留明确区间绑定；切换来源后仅明确primary/warning/danger阈值角色按来源语义映射。HR为正常/警告/危险三段，电量按危险/警告/正常排列；不沿用旧数组位置。步数等无对应状态区间的来源不带旧心率阈值。禁止两个不同颜色控制争抢同一图层同一状态角色。

解除一个颜色关联时，把当前配置色写入该图层对应属性，再删除该引用；其他成员仍跟随原角色。最后一个引用移除时清理该配置及主题引用，其他配置保留。可换色矢量/遮罩图标服从颜色角色；预着色PNG保留原像素，须转换遮罩或使用主题图片变体。

## AI与交付边界

公开对话fontRole操作支持create（roleId/name/fontId/layerIds）、bind（roleId/layerIds）、set（roleId/fontId）和detach（roleId/layerId）；colorRole支持classify（controlId/semantic）和detach（controlId/layerId/property）。单对象font操作自动解除该对象的字体角色。所有操作仍校验当前主题、成员锁定、字体许可身份和事务原子性，不直接改私有嵌套对象。工程提示提供角色说明，但实际Layer字体是生成依据，不得凭空增加运行时字体菜单。

旧Schema48迁移只提升版本并保留旧设计身份与资源。旧外部widget/release-v2不扩展；新主题交付契约另行定义，不以本字段声明其已支持。

共享主设计中的混合AI事务每步同步有效主设计与覆盖，整次事务只提交一个设计版本；拒绝时不修改原项目。角色定义参与对话指纹，角色变化后过期回复不能应用。
