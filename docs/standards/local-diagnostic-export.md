# 本地诊断包

编辑器生成检查旁的“导出本地诊断包”由用户主动下载JSON，不调用模型，不上传服务器。默认只有项目身份/修订、协议/能力/生成器/设备元数据版本、生成诊断、源码路径和字符数，以及当前项目匹配的编译日志。SDK/模拟器/真机状态不从日志或生成成功自行推断。

设计结构、最近一条本地请求、当前预览样本分别选择，默认关闭。最近请求可能属于其他项目，界面明确提示；不自动导出全部历史。结构保留复合父对象/部件，图片与字体字节、源码正文、设计/代码历史、配置档案、鉴权凭证均排除。传入当前浏览器各模型Key供精确脱敏，但不输出档案本身。

JSON有预览；已知Key、常见凭证字段/模式、本地路径、IP与URL/data内容经过脱敏。脱敏是辅助，分享前仍应检查文字及请求。最多1MiB，超限明确拒绝；长文本标记截断，日志只保留末24000字符。诊断包不是可导入备份，缺失资源会限制视觉复现，项目完整备份仍使用原有导出。
