# 项目资源检查

编辑器「素材 → 项目资源检查」在浏览器读取项目图片和资源字体，按图片内容合并统计，但逐一保留当前设计、设计快照、代码版本及多设备变体的引用位置；复合内部图片定位父对象。该视图为只读，不清理素材，不改变现有历史引用回收规则，不上传图片。

图片显示原始编码体积、实际像素、是否存在非255透明像素、原图RGBA估算（宽×高×4）。编码体积仅支持PNG/JPEG/WebP的base64数据。16MiB以上编码资源不解码，4Mi像素以上不扫描透明通道，失败明确显示未知；不会加载外部URL。解码检查只在展开时执行，同一素材复用结果。

RGBA体积是浏览器像素数组估算，不是目标设备内存承诺；佳明打包、调色板、运行时缩放与资源缓存均可能不同。字体先列引用，字节/图集、内置矢量图标的栅格结果和运行峰值待工程生成/SDK/设备检查，不编造数值或通用机型预算。当前没有素材删除入口，历史中的图片与字体继续保留。

Rider只作为本地原稿还原和验证样例，不加入默认表盘库。
