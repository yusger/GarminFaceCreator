# 整盘主题预设与AI公开操作

项目Schema38沿用ThemeSet.version=1，新增可选 `themes.overrides[themeId].backgroundColor`，仅允许合法现有themeId与十六进制色。未提供的背景覆盖读取对应preset默认色。旧Schema37顺序迁移，身份不变。

解析顺序：主题默认背景→该主题背景覆盖；数值/颜色/装饰仍通过已登记控件controlValues解析，互不污染其他主题。当前主题恢复默认仅清除该主题控件和背景覆盖，不回滚几何编辑，不清除公共或其他主题参数。复制、快照、撤销、导出保留覆盖。

AI对话公开操作：

- `{"type":"theme","action":"select","themeId":"已有ID"}`：切换完整主题。
- `{"type":"theme","action":"reset"}`：恢复当前主题配置默认值。
- `{"type":"background","color":"#112233"}`：修改当前主题背景覆盖；无主题项目修改项目背景。
- `control/update/remove/part`仅作用于当前主题及公共对象。调整其他主题先明确select；不允许直接修改私有themes内部结构。受控颜色/来源更新写controlValues，原始默认值不变。
- 新增普通或复合控件归当前主题；锁定对象不能被更新/删除/间接重置。整轮原子应用，失败保持原设计。

对话指纹包含主题与覆盖，主题切换后旧响应必须经现有身份检查丢弃。工程DTO和确定性生成使用有效主题背景，保留全部主题。

本阶段完成的是编辑器/AI背景覆盖与作用域；不因此宣称手表端新增背景颜色选项、原生菜单持久化交互或真机验收已完成。
