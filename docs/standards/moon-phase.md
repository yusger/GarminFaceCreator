# 月相与月面照明（估算）

算法固定参考[SunCalc 1.9.0](https://github.com/mourner/suncalc/blob/v1.9.0/suncalc.js)，保留BSD-2-Clause版权及完整许可。不是Garmin传感器/实时天文服务，也不是用固定29.5天线性进度代替真实照明。地心日月坐标近似得到月相周期位置和可见照明比例；没有观测地的视差、地平坐标倾角、月食或精密历书推算。支持UTC2000-01-01至2038-01-01之前；范围外/非法时间为缺失。

月相是独立moon对象，颜色、暗面颜色、位置尺寸及南北镜像可编辑；北半球示意为上弦右亮、下弦左亮，南半球水平镜像。这是图示方向，不代表当前观测地天空的月面旋转。图形16–128设计单位，每项目最多8层，亮屏按目标物理像素中心判定覆盖、每个图标最多128行，AOD明暗边界最多25点；首版不支持整体旋转/半透明。月面照明读数来源moonIllumination为0–100%，与月相周期进度区别；所有有效读数强制带~，关闭普通装饰也不会隐藏估算标记。真实0保留，缺失为--。

网页和原生按UTC10分钟边界计算并缓存，切换时区不改变同一时刻的月相。原生AOD只读缓存，简化为外边框及明暗分界；启动直接息屏且未缓存时显示缺失轮廓，不启动定位、联网或传感器采样。来源无额外权限。月相图标和数字共用同一份受管GfcMoon算法；AI可通过公开moonHemisphere及已批准kind/source选择，受管源码禁止模型修复。

12个2026年已知相位时刻以[美国海军天文台UT表](https://aa.usno.navy.mil/calculated/moon/phases?year=2026)为对照：测试标准为周期位置误差<0.02、照明比例误差<0.04。这是所测时刻的回归阈值，不是2000–2037每一时刻的全球精度保证。实际偏差及网页/SDK/原生截图须另附证据；仅构建通过不等于已验收。

完整许可在resources/licenses/suncalc-1.9.0-LICENSE.txt、帮助“关于与致谢”可查看；采用月相的源码导出含notices/suncalc-1.9.0-LICENSE.txt，受管源码保留版权。分发该功能的程序时也应随附许可。

AOD在照明≤0.5%时只保留外框，≥99.5%时增加内圈表示满月，其他情况画明暗边界，避免端点附近将同一圆弧反复描粗。这是低亮度示意规则，不修改照明读数。

预览显式utcOffsetMinutes优先；未提供时与其他时间控件一致，按所选日期的浏览器本地时区解释时间（含该日期夏令时）。固定验收夹具必须明确偏移，不能把本地显示时间直接当UTC。

极窄月牙不以退化多边形绘制，避免原生将不足一像素的面取整成整条亮弧。网页与原生共用像素中心/取整规则，16–128设计单位还须满足物理边长≤128px；超过时阻止生成，不能裁掉底部行。
