# 主题定义升级与自定义值兼容

编辑器的“表盘配置 → 更新主题定义”接收一个设计项目JSON（≤20MB），先预检、列出版本和兼容值，再由用户应用。整个流程在浏览器内，未调用模型或上传文件。内置参考请先复制为“我的表盘”。这是显式设计更新，不是第三方自动发布API。

更新需通过当前项目验证器，包含至少两套合法预设；与当前项目具有相同appId，或匹配当前referenceId来源；目标型号/尺寸相同。这里的身份字段用于避免误用更新包，不是数字签名或文件可信度认证。至少一个主题升级版本或新增主题，不允许降级。已有锁定对象若会改变或移除则整体拒绝。

应用替换布局、默认值、主题资源、字体与背景，保留当前项目ID、appId和名称，使再次编译仍使用同一侧载应用身份。更新文件中的代码、代码快照和设计快照不进入当前项目；旧代码标记过期，必须重新生成。

按稳定controlId、相同类型及相同主题归属保留用户颜色/开关/数据选择。数据来源已移除、类型改变、配置跨主题或被删除时，移除该覆盖并显示诊断，使用新定义默认值。每主题背景覆盖仅在对应主题仍存在且颜色合法时保留。未知或已移除的活动主题回退到新定义默认主题；不会借此清空其他主题的合法自定义。

主题版本升级会替换手动布局和原始设计属性；它们并非controlValues中的配置覆盖。预检界面明确告知替换范围，用户可撤销；撤销帧包含布局、主题、配置、字体和二进制素材，避免字体或素材升级后无法还原。预检之后若项目发生修改，必须重新检查更新文件。

当前限定单设备设计；有multiDevice覆盖的项目拒绝更新，先导出单设备副本。更完整的多设备升级映射、新外部主题包规范及原生跨PRG/SET升级实测仍是后续工作，不能以本页面更新测试代替这些验收。
