# 确定性工程控件源映射

本地生成器basic-33-layer-source-map在每个实际输出的亮屏/AOD绘制段写入成对的安全编码注释，记录父对象ID、私有部件ID、能力ID和模式。sourceMapFor解析最终工程文件的实际行号（不是预先估计偏移），所以后续平台图标/文字辅助方法插入不影响标记重新计算。异常/未闭合/嵌套/非法标记使该文件整份映射拒绝。ID经URI编码，不可能把换行注入原生注释。注释不执行也不进入PRG绘制。

编译日志保留原始诊断和打开源码行入口。仅当前项目/目标/尺寸/设计修订与实际提交源码仍一致，且来源为未修补的确定性工程时，可靠绘制段诊断额外显示「定位控件」。复合内部问题定位父对象，不拆开私有层。切换项目/设备、设计或源码变动、刷新丢失本次构建快照、AI工程、手动/AI修补、旧版无标记代码均不猜造控件归因。

公共辅助函数、资源生成与平台启动部分当前没有可靠逐控件行段，保留源码/原始日志；没有把任意source/App.mc错误都归到某个对象。资源路径和资源图集预算映射需要另行完善，当前交付覆盖本地控件绘制段。
