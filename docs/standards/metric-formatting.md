# 数据格式联动与最大读数检查

内部项目v31新增可选metric.autoSourceFormat：按所选数据源确定ASCII标签、显示单位、默认精度（距离2位、温度1位、其余0位），关闭心形装饰。它在配置解析及原生每个数据源选项分支使用同一规则；旧层默认关闭，保留现有手工格式。手动编辑标签/单位/精度关闭自动模式，取消勾选时固定当前显示格式。阈值、配色和用户量程不由此标志覆盖；仪表源切换沿用步数10000、电量100的显式默认目标，阈值需按所选来源检查。

metric.readoutSample最多48字，仅用于当前图层最大读数宽度检查，不替换网页动态数据，不进入生成DTO或确定性源码。默认样本不是数据最大值承诺，可自行填更长样本。检查使用当前网页字体、标签/单位/装饰和框宽，提示近似溢出，不能保证设备字体/AOD的精确排版。

网页与原生共用metricLimits：保留合法零、负海拔和负温度；心率必须大于0，电量/湿度/压力指数0–100，秒0–59，计数/距离非负；温度保留现有原生-273.15至1000的防御边界。所有值须有限且绝对值小于1e12，该边界是软件防御，不是传感器量程或设备支持证据。缺失使用占位，不捏造读数。数字分组仅处理整数部分一次，保留小数与负号，不无条件给步数加逗号。

本次不扩展外部发布格式，不将readoutSample作为AI可写真实数据字段。
