# 所需字形与字体资源检查

原生资源字体仅来自已有许可字体库；不提取或分发SDK字体。chalkPlans根据时间、日期、实际文字、联动标签、数值/分隔/单位/缺失装饰以及所有可配置数据源选项推导所需字符；不再默认给每个数据层打包整段ASCII。AOD未启用时不额外建息屏字号计划，目标像素沿用454逻辑字号→目标宽度比例，资源ID保持稳定。最大读数排版样本不参与原生字形。

preparedChalk在绘制前读取真实字体字节cmap，缺少任一所需字符即失败并说明缺字，不允许浏览器回退字形冒充资源字体。普通浏览器预览和草稿可以保留；字体库缺字检查/盘面导出检查与工程字体准备的证据分别保留。维护者默认字体快照脚本也先检查真实字体覆盖。

素材→项目资源检查→检查生成字体，只在本地读取许可字体并生成当前设计图集，列目标像素、字形数、字体字节、图集宽高、PNG编码及RGBA估算；不上传，不改历史。异步结果按当前项目失效，不覆盖变动后的资源报告。图集现有预算512×2048，超限/缺字明确失败；RGBA不是佳明真实运行内存。系统字体、字体字重差异、固件字形与真机可读性仍需独立验证；该报告不宣称任意TTF/FNT导入或原稿Consolas精确还原。
