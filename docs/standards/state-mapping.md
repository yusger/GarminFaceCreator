# 数据状态映射

复用Layer.visibility与现有Compound.parts，不新增平行状态模型。选择一个基础图层可创建心率四态或电量三态，所有变体放在一个复合对象内，顶层保持一个对象。心率区间为<100、100≤HR<120、120≤HR≤140、HR>140；电量为≥30%、10≤电量<30%、<10%。有效零电量可匹配，缺失/越界或无效心率默认全部隐藏，不把缺失当作低值。

右侧「数据状态映射」可为每个部件设置心率/电量/步数区间、包含/排除边界、缺失显隐与AOD行为，沿用可见条件编辑器及原生规则。多个匹配条件会同时显示；部件启用、亮屏/AOD和导出开关仍生效。状态配色用于文字/矢量，创建的metric状态变体关闭旧阈值以使用该状态颜色，原始设计可整轮撤销恢复。跨部件主题色控制不被隐式改写。彩色位图不被状态色替换，包含一张图片的部件可本地更换状态图片，分配新assetId，其他状态保留原图。

上传只在浏览器转PNG（最大8MB输入、输出长边≤1024）并随本地项目保存，明确编译/导出时才按既有流程使用资源。已有外部配置/标签引用、锁定/复合对象或多设备项目拒绝自动建组，避免丢失引用/设备微调；可在启用多设备前建组。AI仍不能写私有compound结构，现有公开part开关与配置保持有效。
