# 内置单色图标的原生改色

Venu4两尺寸、可改色libraryIcon、宽高均为6–128物理像素时，生成器将授权SVG光栅化为白色灰度字形。使用原始透明覆盖率，颜色由绘制时的参数控制；AOD使用该层aodColor，项目颜色控制可驱动亮屏图标颜色。使用图层opacity调制覆盖率，不额外上传素材或调用模型。

每层一个受管字形字体；静态图标一个字形，天气图标按既有九类（含missing）映射，沿用共享天气缓存。总计最多96层、131072物理字形像素，每图集≤512×2048。这是保守预算，不等于所有组合均已通过设备内存和功耗验收。

受管GfcIcons保留原三参数draw调用作为默认亮屏颜色包装；新绑定draw...Tint显式传亮屏或AOD颜色。受管resources/fonts/gfc-library-icons.xml由平台生成，不允许AI修复修改。SDK9.3已测设备字体顶部内边距使用y−1补偿，后续SDK升级须截图复验。

其他设备、彩色图标或超出物理尺寸范围继续使用既有位图路径，不能据此声称支持新增动态改色。普通静态图标也不会自动读取数据；状态、阈值与数据槽绑定仍须显式配置。文件许可、归属和源码导出沿用原图标素材链。

本规则用于修复原生截图实测的默认位图抖点和AOD颜色未生效；代码/SDK通过不代替修后原图对照。第一轮失败原图需保留，后续将原生截图与网页输出分别比较。


网页同一范围的内置图标使用截断后的目标像素位置及四舍五入后的尺寸；仅影响呈现，不改保存的设计几何和拖动数据。AOD预览与导出使用同一配置颜色，图标透明度同时生效。截图渲染版本升级为browser-capture-4；原四张browser-capture-3基准保存在frontend/tests/baselines/pure-watchface-v1，并记录原始字节摘要，不覆盖原证据。新基准必须量化差异并确认变化只在预期图标区域。
