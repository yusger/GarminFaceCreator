# 组件主样式与实例（Schema50）

组件仍是一个父对象；其内部部件不因此变成独立画布对象。主样式是一套可复用外观，实例保留各自数据和位置。

## 结构与同步

项目`componentStyles[]`最多24项，每项包含稳定id、名称、整数version、内部坐标基准width/height及最多40个slots。每个slot有稳定key、名称、kind和受限style。父图层`componentStyle`明确记录主样式id/version及slot-key → 内部图层id映射。身份仅支持安全ASCII标识；禁止重复、缺失、保留对象键名或类型不一致的映射。

首版style严格使用`compoundStyleKeys`：内部x/y/w/h/size/rotation、颜色/描边/线宽、圆环宽/弧字间距、亮屏导出/隐藏及AOD外观等现有微调字段。**不包含字体族、文字内容、数据源、阈值规则、素材、部件结构和配置身份**。不能将结构不同的两个控件自动按数组顺序配对；关联时用户逐项选择一一对应关系，内部坐标基准也必须一致。

“创建并关联主样式”从当前实例有效外观建立v1。“用当前外观更新全部实例”发布下一整数版本，原子更新所有关联实例基础外观；源实例微调提升为新默认并清除，其他实例和目标设备已有微调继续覆盖。内部颜色配置同步默认色时保留显式controlValues；配置颜色和实例微调的解析仍沿用既有复合控件规则。

更新保留父对象x/y/w/h、实例来源/配置值、公开部件enabled/active/aod及disabledLayers。图形内部尺寸属于样式，可随主样式变化。修改关联实例内部外观时，编辑器将变化保存为`compoundOverrides`；不会直接破坏主样式基础值。清空某个继承属性不提供通用null覆盖，需要脱离关联后调整。

## 脱离、删除、版本与资源

脱离只移除关联，保留实际子图层、配置、微调和许可，外观连续。主样式仍被任何实例引用时禁止删除。主样式或版本缺失、映射不完整、基础外观被绕过修改时明确拒绝项目校验，不猜测修复。独立字体、图片和第三方控件原始来源始终保留；本功能没有资源库远程删除或自动升级能力。

样式发布在共享主设计进行；设备微调范围禁止编辑定义。任一关联实例锁定会阻止整个发布，失败不留下部分更新。多主题实例可以共享定义，发布会作用于全部关联实例；修改前请确认面板中的实例数量。

撤销/重做、设计快照、导入/导出、复制父对象和设备变体均保留定义及关系。复制时重建内部id与显式映射，不能保留指向原实例的私有id。保存与历史切换使相关工程代码过期，需要重新生成。

## AI、原生与外部包

AI公开操作仅`componentStyle create/publish/detach`，目标为当前主题的公开复合父对象；不能直接提交主样式定义或私有映射。父对象锁定、未知操作及非法字段导致整次操作失败。bind需要用户在面板中确认内部映射，未向AI开放隐式匹配。

原生生成使用已经落实到子图层的有效外观，不引入运行时样式引擎，不增加手表设置类型。原有几何、字体、数据、AOD和内存限制继续适用；不开放嵌套或父对象整体旋转。

冻结的旧widget/release v2及theme-project-v1(Schema49)不接受这些编辑器元数据，保持封闭边界。需要按旧外部profile交付时，必须明确脱离实例、删除未使用定义并按对应schema整理，不能带着关联信息冒充旧格式；完整Schema50项目JSON仍可通过常规本地项目导入保留关联。自动发布API仍未上线。
