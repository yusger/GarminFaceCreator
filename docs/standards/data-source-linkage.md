# 数据源联动规则

此规则复用现有项目与配置结构，不新增执行脚本、图层类型或外部包字段。

| 对象 | 切换数据源后的规则 |
| --- | --- |
| 数据控件开启自动格式 | 标签、显示后缀、精度按共享契约重新计算；纯数字装饰。距离2位、温度1位、其余0位。手动改格式关闭自动匹配。 |
| 独立文本标签 sourceLabelFor | 跟随被引用数据控件的ASCII来源标签，不替换为固定读数。 |
| 静态图标/图片 | 默认保持原设计；可在“表盘配置→数据项的图标联动”显式勾选，仅默认数据源显示，切换后亮屏/AOD均隐藏，恢复默认时还原原图及AOD设置。不开启自动改画、不猜测相邻图层归属。 |
| 天气条件图标 | 使用独立已登记的条件映射，不能当成静态来源图标联动。 |
| 秒环/进度环 | 手动切换来源清除旧目标，按秒60、步数10000、电量100、心率180、静态1的设计默认值；自定义目标保持到下一次手动换来源。 |
| 目标仪表 | 切换步数/电量将设计目标设为10000/100，可再手动修改。 |

这些目标是设计值，不能称为Garmin个性化目标。手机数据源配置仍只面向允许的数值控件；不会连带改写独立环/仪表。需要联动的静态图标必须显式选择；不会删除资源或原图。复合私有层不出现在全局图标列表，复合公开接口继续独立管理。

hideWhenChangedFromDefault 在网页和工程的亮屏/AOD均执行；activeVisible布尔配置仍只控制亮屏。未知数据/硬件能力仍按缺失或未验证处理，不因联动变为支持。每次变更重新生成工程；代码历史保留。
