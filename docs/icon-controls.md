# 图标遮罩与数据来源映射（阶段C1）

图片图层可显式启用透明位图单色图标，丢弃RGB仅保留alpha；网页使用alpha mask，原生制作单字形FNT/灰度PNG并以前景色绘制，从而支持运行时颜色配置。默认仍保留原彩色图片。每图标目标尺寸最多128px，单工程最多96个，不能将整盘背景误当图标。既有单对象复合状态映射可为图标设置阈值显隐/变色及替换状态图片，不新增平行状态模型。

数据来源配置的sourceIcons显式关联各来源的图标ID；不匹配时亮屏/AOD隐藏，原生保留所有选项资源和条件绘制。旧hideWhenChangedFromDefault继续兼容，不能同时给同一图标设置冲突映射。静态图片不会被平台自动推断为电池填充或实时心电图。主题图标归属必须同主题，跨主题映射拒绝。

Schema35、生成器basic42增加能力；编译仅显式制作使用资源，图片依旧本地保存。自定义图标入库、类别缺失规则与完整三主题视觉仍需分别验收。本轮不声称任意彩色位图可无损改色。
