# trail：一个项目的三套完整主题

从内置表盘的「trail」默认参考卡片创建可编辑副本，选择Apex、Trail或Vital。在resources/default-watchfaces/trail按标准默认参考描述维护，卡片使用“默认参考 · 不可删除”和自主标签。Apex/Trail/Vital仍为一个表盘的三套主题。原设计来源、字体与许可、固定预览及转换记录均保留。

三主题合为一个应用身份，121层（含60个替换图标备选，共享6份原生图标字形）、37个独立配置及2份共享本地字体。主题切换保留各自颜色、数据来源、背景/外圈/秒数或装饰条开关，恢复默认仅清除当前主题配置。更换数据同时调整标签、显示后缀、来源精度和图标，AOD读数跟随同一槽；背景心电线和外圈仍为静态装饰，不当作历史/ECG。缺失心率时静态分区条隐藏以免被误解为有效分区。

本轮修正：日期按ddd DD保留；电量数字和进度统一阈值；Apex AOD单位避开三位心率；原预览里的技术解释字幕不绘到实际盘面。其他差异逐项记录，不以旧包自带pass当作设备通过。

维护：node scripts/build-native454-study.mjs，随后npm run build发布可编辑起点。内部Schema36/basic43新增来源显示标签/后缀/精度、日期及进度阈值衔接；外部整盘自动发布契约不因此自动扩展。

状态：113三主题网页、整包SDK及454px原生截图已通过（阶段116）；尚未完成固定数据的三主题/AOD完整视觉矩阵。手表菜单真实交互、Sleep/AOD和真机验收仍待验证，付费模型视觉对照另记；此文不宣称整盘已完美交付。
