网页预览、SDK 编译、SDK 模拟器和真实手表是不同验证层。远程自动化通过不表示所有目标均完成真机验证；字体、功耗与刷新限制按实际设备检查。

## 从设计到原生显示

- 确认型号、表壳毫米尺寸与像素分辨率未混用，manifest 仅列当前 target；按 dc.getWidth()/getHeight() 缩放坐标、字体和线宽。
- 检查圆屏边界、旋转对象、长时间/大步数/负海拔、标签单位及缺失值；允许裁切仅用于确定的装饰。
- 验证中英文字形、替代字体与 Garmin 系统字体差异，不因网页显示中文就推断设备字体已支持。按实际输出语言检查资源与最低 API。
- 图片实际出现在模拟器中，透明边缘、位图字体图集及资源 ID/路径一致；中文素材名称保留在 UI，原生工程路径采用 ASCII。
- 0/59 秒、跨分钟、阈值边界、未命中区间、传感器缺失与异常值均有明确行为。
- 息屏仅显示选定图层，独立颜色/字号正确，秒数/圆环停止动画；真机检查亮屏唤醒、低功耗切换、像素占用和长时间使用，不用网页估算虚构续航。
- 数据源权限、网络/后台行为和缺失 API 应有回退；示例天气/天文/历史图不冒充真实设备数据。

## 保存、导出与敏感信息

- 双标签页冲突不会覆盖未保存设计；配额失败时可导出和恢复。清除浏览器数据会删除本地项目，先备份。
- JSON 备份包含当前画布、素材及历史，可能包含用户自行绘制的个人内容；不包含编辑器的模型配置或认证头。导入当前仅恢复画布，并明确丢弃代码及快照。
- 源码 ZIP 包含已应用代码与所需资源/原作声明，检查版本一致；不包含模型 Key、SDK、私钥或服务器目录。用户自行写入源码的敏感常量仍需自行审阅。
- PRG 是签名编译产物，不包含私钥文件；需要长期保留时在产物过期前下载。源码/素材和日志应独立备份。
- 不要把包含真实 Key 的模型配置、未脱敏日志或浏览器配置目录提交到仓库；日志分享前检查路径、设备资料及用户内容。
- 本仓库许可不自动覆盖独立输出或角色/图片权利；保留每项实际来源与原始声明，未知许可不得标成已授权。
