# 静态数据条件显示

schema v21 为图层增加可选 visibility，旧工程默认无条件显示。首版数据源为缓存心率、电量、步数；上下限默认包含下限、不包含上限，可以分别排除下限或包含上限。无条件图层仍遵循既有编辑器隐藏、原生导出和 AOD 开关。

PulseManiac 区间为 HR<100、100≤HR<120、120≤HR≤140、HR>140。非有限、负值、非正心率、超过100的电量视为缺失；只显示明确指定 missingVisible 的中性图层。AOD 可对每层指定继续判断/始终通过/始终不通过，仍受 AOD 包含开关控制。首版每次按最新可获取的缓存值判断，不修改用户阈值，不主动持续采样、不添加计时器或动画。

条件是运行时绘制规则，不是源码/资源过滤规则。所有状态与图片保留在工程中；网页预览、导入/导出、AI 提示与本地生成都保留同一规则。条件源即使没有对应数字图层也会声明权限并读取一次共享数据，避免复用错误的静态预览值。

静态 PNG 在资源 XML 中使用相对屏幕百分比 scaleX/scaleY 编译（按目标物理像素换算，显式 screen），保持独立图层位置；不在手表上反复变换或缓冲大图。系统资源只在首次出现或状态切换时加载并缓存，绘制后释放不再可见状态的引用，不预先解码所有人物。沿用原图片；AOD 样式颜色不会给位图自动染色。透明图片仍需检验实际 alpha 与目标 SDK 效果。

中文日期格式为“周三 11月25日”，取设备本地 Gregorian 日期；指定 FONT_SYSTEM_XTINY，并声明所需中文字形。中文文字本地生成仅允许显式选择已验证的 SYSTEM_XTINY 和汉字/ASCII；任意其他字形继续拒绝。字体大小仍以原生系统字体实际效果为准。

资源缩放依据：[Garmin 资源文档](https://developer.garmin.com/connect-iq/articles/core-topics/Resources.html)。
