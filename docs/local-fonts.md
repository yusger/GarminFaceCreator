# 项目本地字体（阶段D1）

字体素材库可导入4MB以内TTF/OTF，先填写许可或授权说明。每项目最多8份、实际字节合计16MB；检查SFNT表边界与Unicode映射。许可说明由用户提供，不代表平台已核实版权。字体和来源随可编辑项目保存在浏览器，导入不发起网络上传；明确编译时制作目标像素FNT/PNG，源码导出保留使用字体和许可。

项目Schema33增加localFonts，稳定ID关联customFont，旧项目顺序迁移。字形来自实际字体字节，网页不模拟另一字重；截图、原生图集、缺字检查和导出共用字体解析。缺少本地字体明确报错，不请求服务器同名字体。设计快照和撤销保留字体；本地身份用于变更检测，不作为密码学证明。

当前交付仅字体文件导入及既有图集制作衔接，FNT/PNG直接导入、字距/等宽数字等排版功能仍待D后续，尚未完整交付阶段D。缓存预算沿用现有原生字体制作限制，设备视觉及资源开销需分别核验。
