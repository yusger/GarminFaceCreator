# 精选静态图标来源

当前阶段固定了 27 个静态 SVG 和完整许可，供后续素材面板接入；此时尚未新增插入入口或动态天气绑定。

- Lucide：心率、步数、活动、电量、日历、温度、海拔、蓝牙、热量和风速，固定上游提交。
- Meteocons：Monochrome 晴天/晴夜/多云昼夜/阴/雨/雪/雷暴/雾/风/缺失，共 11 个；另有 Flat 4 个、Line 2 个。来自官方 svg-static@0.1.0，不使用动画 SVG。
- catalog.json 记录稳定 ID、中文名称、关键词、原文件路径、来源提交/包版本、版权、许可及原 SVG SHA-256；原始文件不做隐藏改写。
- scripts/update-icon-catalog.py 可重新获取这些固定版本；验证 SHA-512 发布包完整性、静态 SVG 条件和完整许可证，只读取明确路径，既不整体解压，也不执行上游脚本。

本阶段验证静态文件在部署环境可访问且字节哈希一致；不据此宣称已插入表盘、已支持天气绑定或小尺寸真机清晰度。后续项目导出应只携带实际使用素材及其许可，不能把整个图库灌入每个项目。

## 静态插入与派生资源

素材页可按通用/天气分类并搜索中文或英文关键词，点击插入；图层保持独立可编辑，属性栏可改颜色、勾选统一色，以及调整 Lucide 线宽。Flat/Line 天气默认保留上游色彩，线宽不可自由改写，统一色属于可选扁平化效果。

schema v10 保存不可变版本素材 ID 与样式，原始 SVG 由固定目录复用；初始透明 PNG 随浏览器项目存储和备份。网页使用安全静态 SVG 预览，编译/源码 ZIP 重新按目标物理像素栅格化，重设宽高后不会沿用旧尺寸 PNG。每层资源路径独立，复制后改色/缩放不会覆盖其他层；相同初始 PNG 仍可由素材存储去重。

源码 ZIP 只收集实际导出的图标：对应 PNG、原始 SVG、完整许可证、来源提交/包版本和样式用法记录。预览或排除层不增加编译资源。天气图标当前仍是静态素材，动态条件/昼夜/缺失回退下一阶段实现。

目录不可用时保留项目中的 PNG 作为预览回退；准确重新编译需要取到固定版本原始素材。SVG 上传范围没有扩张，用户上传仍限 PNG/JPEG/WebP。真机小尺寸清晰度和 AOD 仍需实测。

## 缓存天气绑定 icons-1

Monochrome 天气图标可启用 Garmin 缓存天气绑定，并手动选择日间/夜间样式；未自动推断位置或日出日落，不额外请求定位/联网权限。当前 SDK 的 0–53 条件枚举统一归并为晴、多云、阴、雨、雪/冰、风、雷暴、雾/霾及未知/缺失。恶劣天气仅以概括图形表达，不替代天气警报。缺失、异常、未来未知枚举不伪装为晴天。

网页预览的天气是可选模拟场景，Garmin 原生使用 Weather.getCurrentConditions() 的缓存。两者由同一张分类表生成，原生 GfcIcons.mc 和图标资源声明由前端固定生成，模型只调用对应方法；修复面板不允许改写这些固定文件。按所选昼夜风格导出实际需要的 9 个变体与原始许可，不携带整图库。

schema v11 增加绑定设置。basic-2-icons 本地生成器开始支持内置静态/动态天气图标，保留前一版的 ASCII 文字和未旋转范围限制；亮屏/息屏按图层 AOD 包含策略绘制。默认天气层不在 AOD 显示，不为天气添加秒动画。Flat/Line 的条件绑定和天文自动昼夜不在首版范围内。
