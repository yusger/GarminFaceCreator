# 表盘设计基础规范（Watchface Basic Spec）

> 版本：v1.1
> 定位：产品设计指导与功能开放清单；不是新的交换格式，也不代表所有设想已实现。
> 配套契约：[设计包接入规范v1.2](../docs/watchface-package-standard.md)；AI创建设计使用独立的内部设计协议。
> 适用产品：GarminFaceCreator 可视化表盘编辑器及导出的 ConnectIQ 表盘
> 默认基准设备：Venu 4 45mm；支持从当前设备目录选择系列、型号和尺寸，设计坐标454×454，按目标实际像素适配。
> 规范目的：统一时间模块、子数据模块的字段定义、必选/可选规则、显示格式与数据契约，约束编辑、预览和工程生成的共同语义；字体、原生特殊效果等差异需明确标注并通过模拟器/真机核对。

---

## 1. 总则

### 1.1 坐标系与安全区

- 画布逻辑尺寸固定 **454×454**；编辑器缩放只影响视图，导出 JSON 与代码一律使用逻辑像素。
- 表盘圆形裁切；外圈建议预留 **安全边距 8–12个逻辑像素**，具体由布局和目标设备决定；这不是所有设计的固定强制值。，重要文字、指针端点、数据数值不得落入表壳遮挡预警区。
- 所有元素以逻辑坐标存储；当前锚点支持「左上角 / 中心 / 右上角 / 左下角 / 右下角」，底部中心可通过坐标对齐实现，尚非独立锚点枚举，坐标换算由编辑器统一处理。

### 1.2 模块划分

一个表盘由以下模块组成，可独立显隐、独立绑定数据：

| 模块 | 职责 | 必选 |
| --- | --- | --- |
| 时间模块 | 时、分、秒及日期类信息 | 是 |
| 子数据模块 | 心率、步数等健康 / 设备 / 环境指标 | 否（至少 0 项） |
| 装饰模块 | 背景、刻度、线条、图形、符号、图片 | 否 |
| 状态提示 | 告警、缺失值、低电量、连接状态 | 否 |

### 1.3 术语约定

- **必选字段**：完成的设计须满足该风格要求；编辑过程中允许暂时空白或删除，AI采用设计和发布前再检查，不锁死编辑操作。
- **可选字段**：编辑器中可独立开关，默认关闭或按模板决定。
- **缺失值**：传感器未读数、权限未授权或数据无效时的显示状态，区别于有效零值。

## 2. 时间显示规范

### 2.1 显示风格分类

| 风格 ID | 名称 | 说明 |
| --- | --- | --- |
| `DIGITAL` | 数字模式 | 以数字文本显示时间，无表针 |
| `ANALOG` | 指针模式 | 以时针、分针（可选秒针）显示时间，可配刻度 |
| `HYBRID` | 混合模式 | 时针、分针与数字时分并存；仅指针加日期仍归指针模式 |

AI创建时选择一种主时间风格，用于生成结果校验，不是限制编辑器只能放一套时间。后续可以手动调整或添加第二时区。当前第二时区是固定UTC偏移，不宣称具备完整地区时区/夏令时规则。

### 2.2 时间字段：必选 / 可选总表

| 字段 ID | 中文名 | 数字模式 | 指针模式 | 混合模式 | 格式示例 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| `hour` | 时 | **必选** | **必选**（时针） | **必选** | `10` / `22` | 当前24h；12h待实现 |
| `minute` | 分 | **必选** | **必选**（分针） | **必选** | `24` | 两位补零 |
| `second` | 秒 | 可选 | 可选（秒针） | 可选 | `07` | 当前整数秒；平滑扫秒待实现 |
| `ampm` | 上下午 | 可选 | 可选 | 可选 | `AM` / `PM` | 随12h能力规划，当前未开放 |
| `year` | 年 | 可选 | 可选 | 可选 | `2026` | 通常仅日期区显示 |
| `month` | 月 | 可选 | 可选 | 可选 | `11` / `11月` | — |
| `day` | 日 | 可选 | 可选 | 可选 | `20` | — |
| `weekday` | 星期 | 可选 | 可选 | 可选 | `周五` / `FRI` | 中英文可配置 |
| `lunar` | 农历（阴阳历） | 可选 | 可选 | 可选 | `十月廿二` | 规划：需历法及明确时区，不是已实现字段 |
| `solarTerm` | 二十四节气 | 可选 | 可选 | 可选 | `小雪` | 规划：需明确算法、年份范围及节气时刻，不承诺只查日期 |
| `holiday` | 节假日 | 可选 | 可选 | 可选 | `感恩节` | 规划：需明确国家/地区、年份和数据来源 |

### 2.3 数字模式（DIGITAL）规则

1. **必须显示时和分**，缺一不可。
2. 制式：
   - 24h：`00:00 – 23:59`；
   - 12h（待实现）：`1:00 – 12:59`，AM/PM另行配置；当前AI向导只提供24h。
3. 可选字段：秒、年、月、日、星期、农历、节气、节假日。
4. 层级建议：时分为主视觉（最大字号）；秒、日期类为次级字号，不得与时分抢层级。
5. 秒为可选项：开启时显示秒数或秒进度；关闭时不生成秒层；编辑器手动隐藏已有秒层不自动重排其它控件。

### 2.4 指针模式（ANALOG）规则

1. **时针、分针必选**；秒针为可选。
2. 刻度：小时刻度、分钟刻度、数字时标均为可选。
3. **旋转中心**：默认情况下指针绕表盘主中心旋转；采用多子盘布局时，时针、分针可分别归属各自的小盘，旋转中心为所属小盘的中心，不强制统一到表盘主中心。
4. 指针锚点为其**所属盘面的中心点**；长度、宽度、尾饰、颜色可配置。
5. 日期类建议放副盘或信息区，避免影响读时；位置属于设计建议，不强制禁止中心布局。
6. 当前秒针按整数秒更新；平滑扫秒待实现。AOD隐藏秒针，不将页面动画当作设备实现。

### 2.5 混合模式（HYBRID）规则

1. 指针负责时分，数字区必须有数字时分，可另加秒、日期或关键子数据。
2. 数字区与指针区不得重复争抢同一主视觉位置。
3. 必选字段规则同数字模式 + 指针模式的并集：时针、分针、数字时分至少各满足其风格要求。

### 2.6 日期类可选字段格式

- 公历：月/日分隔符、星期语言（中文 / 英文缩写）可配置。
- 农历：干支、月相、朔望等扩展项属于后续版本，农历月日本身也处于规划阶段，当前不提供伪实现。
- 节气、节假日：未来若共用文本位，优先级必须由设计显式配置，不强制全局互斥或固定优先级；当前不开放。
- 历法字段需随设备时区更新；无数据源时显示缺失值，不显示伪日期。

## 3. 子数据（副数据）规范

### 3.1 子数据项总表

| 字段 ID | 中文名 | 数据源 | 单位 | 必选/可选 | 建议刷新 | 缺失值处理 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `heartRate` | 心率 | 最新心率缓存 | bpm | 可选 | 建议读取缓存30–60s，实际按表盘生命周期 | 显示 `--` | 支持阈值变色区间 |
| `calories` | 卡路里 | 活动统计 | kcal | 可选 | 1min | 缺失 `--`，有效0显示 `0` | 当日总消耗 |
| `steps` | 步数 | 计步器 | 步 | 可选 | 1min | 缺失 `--`，有效0显示 `0` | 可绑定目标进度 |
| `distance` | 当日距离 | 活动统计 | 当前km；mi待适配 | 可选 | 1min | 缺失 `--`，有效0按精度显示 | 当前不自动跟随系统单位制式 |
| `battery` | 电量 | 设备电池 | % | 可选 | 15min | 显示 `--` | 低电量阈值变色 |
| `temperature` | 温度 | 缓存天气温度 | 当前°C；°F待适配 | 可选 | 15–30min | 显示 `--` | 不等同设备传感器温度；冷暖色可选 |
| `stress` | 压力 | 设备压力指标（可用时） | 等级 / 0–100 | 可选 | 1min | 显示 `--` | 低/中/高区间 |
| `altitude` | 海拔 | 海拔历史缓存（当前适配器） | m / ft | 可选 | 缓存可用时更新 | 显示 `--` | 缺失时不臆造；不要求主动开启GPS |
| `windSpeed` | 风速 | 天气缓存 | 当前m/s | 可选 | 30min | 显示 `--` | 依赖天气数据 |
| `notificationCount` | 信息数量 | 待核验的设备通知接口 | 条 | 可选 | 事件触发 | 缺失 `--`，有效0显示 `0` | 未实现；须先明确是设备通知数还是手机未读数 |

### 3.2 扩展数据项（预留，按设备能力开放）

| 字段 ID | 中文名 | 单位 | 备注 |
| --- | --- | --- | --- |
| `spo2` | 血氧 | % | 仅支持设备 |
| `pressure` | 气压 | hPa | 天气 / 登山场景 |
| `floorsClimbed` | 楼层 | 层 | 爬升楼层 |
| `intensityMinutes` | 强度分钟 | min | 与普通运动时长不同，不混用 |
| `sunriseSunset` | 日出日落 | 时间 | 依赖位置 |
| `weather` | 天气状况 | 文本/图标 | 晴/雨/云等 |

### 3.3 子数据通用规则

1. **数据身份稳定**：内部 `source`/ID 保持不变，展示标签可中文化；翻译不得改变数据来源。
2. **单位制式**：当前来源固定使用已实现单位；公英制切换待补齐数值转换和同步单位预览，不得只替换标签。
3. **缺失值与零值区分**：未读数显示 `--`，有效零值缺失 `--`，有效0显示 `0`，二者不得混用。
4. **阈值变色**（可选能力，按数据项配置）：
   - 心率示例：`<120` 绿，`[120,150)` 黄，`≥150` 红；
   - 电量示例：`≥30%` 正常，`[10,30)%` 黄，`<10%` 红；
   - 规则区间不得重叠；必须配置**兜底缺省颜色**，用于未匹配区间与缺失值。
5. **刷新与功耗**：高频刷新（动画、实时传感器）需在编辑器标注功耗提示；AOD 下子数据按 6.3 节降级。
6. **进度型数据**（步数、卡路里、活动时长）可绑定目标值，支持进度环 / 半环 / 指针副盘形态；目标值按现有控件属性配置；不是自动同步设备运动目标。进度控件目前只支持步数/电量，其他来源和数据指针副盘待实现。

### 3.4 数据分组建议

| 分组 | 包含数据 | 展示建议 |
| --- | --- | --- |
| 健康指标 | 心率、血氧、压力、卡路里、步数、距离、活动时长 | 主副盘 / 信息条 |
| 设备状态 | 电量、信息数量 | 角落小图标 + 数值 |
| 环境天气 | 温度、风速、气压、天气、日出日落 | 天气副盘 |
| 户外海拔 | 海拔、楼层、气压 | 登山模板专用 |

## 4. 布局与视觉规范

### 4.1 分区建议

| 区域 | 位置 | 允许放置 |
| --- | --- | --- |
| 主时间区 | 中心 / 底部主视觉 | 时、分、秒、指针 |
| 副盘区 | 左 9 点 / 右 3 点 / 上下方 | 指针副盘、半环进度、数字数据窗 |
| 信息条 | 底部或两侧 | 心率、电量、温度等次级数据 |
| 装饰层 | 背景、外圈 | 刻度、符号、图片、纹理，不遮挡主时间 |

### 4.2 层级与可读性

1. 第一层级：时分（或主指针）；第二层级：秒、关键子数据；第三层级：日期、农历、节气、节假日。
2. 同一屏子数据建议不超过 4–6 项；超出时放入可切换副盘，避免拥挤。
3. 文字字号、颜色对比度以真机可读为准；网页预览不代表真机效果。
4. 装饰元素不得降低主时间与心率等关键数据的可读性。

### 4.3 组件形态

| 形态 | 适用数据 | 说明 |
| --- | --- | --- |
| 数字读数 | 全部子数据 | 标签 + 数值 + 可选单位 |
| 指针副盘 | 步数、卡路里、活动时长、压力 | 规划：当前hand只绑定时间，不能直接绑定任意数据进度 |
| 进度环 / 半环 | 步数、卡路里、电量、秒 | 环形或半环形进度 |
| 图标 + 数值 | 电量、天气、信息数量 | 角落精简展示 |
| 心形 / 电表 | 心率 | 形态可配置 |

## 5. 数据绑定与状态规则

1. 每个数据组件必须绑定明确 `source`；未绑定的数据组件在生成前校验清单中标红。
2. 数据单位、有效性及权限由当前数据适配器和生成需求统一定义；刷新间隔是缓存读取期望，不代表主动采样或保证新鲜度。
3. 规则变色需声明：区间下限、上限、颜色、兜底色；区间自动排序、重叠校验。
4. 状态滞回为规划能力，当前只接受0；非0需定义初始状态、跨档、缺失重置等语义后再实现，不能强制要求现有表盘启用。
5. 设计快照与代码快照分离；数据契约以导出的设计 JSON 为准。

## 6. AOD 息屏规范

### 6.1 保留与隐藏

| 类别 | AOD 保留 | AOD 隐藏 |
| --- | --- | --- |
| 时间（时、分） | 是 | — |
| 秒、秒针、动画 | — | 是 |
| 关键子数据（心率、电量） | 可选 | 非必要项 |
| 装饰残影、速度线、特效文字 | — | 是 |
| 高频刷新组件 | — | 是 |

### 6.2 降级规则

- AOD 下颜色降级为低亮度 / 黑白；关闭动画与呼吸闪烁。
- 每个图层可独立配置：AOD 是否可见、AOD 颜色、AOD 禁用动画。
- 息屏模式以降低点亮像素与刷新频率为优先，不保证展示全部可选字段。

### 6.3 功耗提示

- 编辑器状态栏给出非精确参考提示：高频动画、高频刷新会增加耗电；SDK编译不证明续航，实际功耗、烧屏与性能以真机测量为准。
- 网页预览不冒充真机功耗、烧屏或性能验证。

## 7. 当前开放等级与实现边界

| 能力 | 当前状态 | AI创建首版 |
| --- | --- | --- |
| 24h时分、整数秒、数字/指针/混合 | 已有对应控件 | 开放；时分必选，秒可选 |
| 英文/中文日期 | 组合日期控件已存在，非任意日期格式 | 开放日期开关和语言；独立年月字段待扩展 |
| 心率、总热量、步数、距离、电量、天气温度 | 已有内部适配器 | 开放；缺失统一-- |
| 压力、恢复时间、楼层、强度分钟、湿度、紫外线、海拔、风速 | 已有内部适配器，依赖目标API及缓存 | 开放选择；不保证每个设备都有读数 |
| 通知数、血氧、气压 | 当前AI数据目录未接入 | 暂不开放，不生成伪数据 |
| 日出日落/天气图标 | 内部有专用控件或素材机制 | AI创建首版未开放这些专用形态 |
| 第二时区 | 内部固定UTC偏移 | AI向导首版不配置，创建后可手动调整 |
| 12h/AMPM、农历、节气、节假日 | 待实现 | 不开放 |
| 进度条/环 | 已有控件；meter为步数/电量，ring另支持秒/心率及静态 | 仅使用已实现来源与形态 |
| 自定义原生效果 | 效果说明不等于网页渲染器 | 保存effectPrompt，后续用户点击AI生成工程时实现；网页静态近似 |

上述是内部产品能力，不扩张外部接入规范formatVersion 1的七种source。内部字段与外部交付字段须经过明确适配，不能混用。

## 8. AI创建表盘工作流

首页在空白画布旁提供“AI创建表盘”：设备及名称 → 时间风格/秒/日期/子数据 → 模型/参考图/提示词。勾选子数据可以为空，不预先锁定布局，由AI安排。

1. **生成表盘项目**：浏览器使用已有本地模型配置，直调兼容接口，只请求backgroundColor与独立layers，不请求Monkey C、设置XML或编译。不自动重试模型请求。
2. **预览及采用**：校验返回字段、圆屏边界、时分风格、勾选来源、秒/日期选项，不能把坏结果当作成功或偷偷补模板。采用后保存为新的本地可编辑项目，身份由程序生成，不由模型分配。
3. **手动调整**：移动、删除、替换和修改控件不调用模型。特殊效果说明为可选effectPrompt，随控件保存、快照、导入/导出；网页显示基础布局和原生效果提示。
4. **生成工程**：用户明确点击现有AI生成代码入口后才消耗第二次模型请求。当前图层是事实来源，初始designBrief只供理解风格，不能覆盖后续手动调整。含effectPrompt时，本地生成必须提示不支持，不能静默忽略。
5. **编译与下载**：编译已有工程不调用模型。设计变化后代码标为过期，保留旧版本，不自动重新生成。

参考图最多3张、每张原文件4MB；浏览器转换为PNG，最长边不超过1600像素。用途分别为风格参考、布局参考和实际素材；只有实际素材可以作为运行图片。图片发送需要所选模型支持图片理解；不支持时保留输入供用户换模型，不自动丢图。

参考图片不发送到编译服务器来生成设计；若作为实际素材被采用，则随本地项目保存，并在用户后续编译时作为运行资源发送。首版不调用生图服务，不承诺无素材即可生成照片/人物位图，不把整盘参考截图烘焙为可编辑数据。
