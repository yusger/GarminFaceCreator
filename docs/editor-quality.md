# 精细表盘编辑能力

## 本轮实现

- 预览：最长/最短读数、负温度/海拔；从当前设计（含复合控件）提取阈值、条件显隐、进度目标的边界两侧。测试数据不写入设计、不代表传感器实际量程。
- 排列工具：水平/垂直等距、圆周复制与分布。角度从12点顺时针，整圈不重复末端，弧段包含两端；份数包含原件。复合控件保留独立内部身份，暂不支持整体旋转；锁定对象不参与。副本是当前样式快照，不自动共享外层项目配置。
- 字体素材库：图层属性中打开，四份已有授权字体可搜索、真实预览和应用；显示逻辑字号及目标像素估算。Unicode字符表检查仅针对输入样本文字；系统字体仍需设备核对。生成沿用现有按设备制作FNT/PNG流程，字体和许可随源码ZIP导出。本轮未开放用户任意字体上传、FNT导入或字体在线下载。

## 与精细示例表盘相比，后续优先补齐的能力

1. 连续圆弧/圆角进度、弧形文字和精细路径。静态盘面优先保留矢量几何，复杂纹理用独立局部PNG；时间和读数继续实时绘制。
2. 统一数据定义，数值、单位、标签、图标和量程联动；扩展传感器/Complications前逐设备核验。
3. 可复用仪表复合控件，包括多环活动、天气信息带、仪表副盘和状态映射。每个实例仍为一个完整对象。
4. 数据历史图表：先定义实际数据源、采样周期、缺失和缓存，再做曲线/柱图，避免仅有静态装饰图。
5. 低功耗与设备验收：字体资源体积、绘制复杂度、AOD包含及更新策略的可检查报告；真机实测才可判断耗电。
6. AI统一能力目录：设计预览、受限操作与原生生成使用同一套能力定义，优先调用成熟控件，不依赖效果提示词猜测已实现行为。

本文是产品优化路线，不扩展现有交付格式字段或承诺未实现能力。对第三方规范的调整需与Schema、转换器和设备验收同步。远程安装按用户要求暂不考虑。
