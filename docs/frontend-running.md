# 前端运行与已实现范围

前端使用 React、TypeScript 和 Vite，适配桌面浏览器，已接通 .NET 10 编译服务。默认访问 http://localhost:18380 ，本机不启动服务。

## 可选本地开发启动（默认不使用）

需要 Node.js 24（本次验证为 24.12.0）或符合当前 Vite 要求的 Node 版本。

在 GarminFaceCreator 目录执行：

```powershell
npm.cmd ci
npm.cmd run dev
```

浏览器访问 http://127.0.0.1:5173 。Windows 也可以双击 `start-frontend.bat`。开发服务默认只监听本机。

```powershell
npm.cmd run build
npm.cmd run preview
```

生产静态资源输出到 `dist/`，不进入 Git。项目设计和模型配置保存在浏览器，不随服务器重启自动删除。

## 使用流程

1. 项目页新建基础数字表盘或空白项目，进入编辑器。
2. 左侧添加控件，直接拖动画布元素；四角均可改变宽高，取消拖动回滚；Shift 多选、空白框选，Alt 拖动暂时关闭中心线吸附。
3. 右侧调整位置、尺寸、旋转、字号、颜色、数据源、阈值及息屏显隐。
4. 图层支持排序、隐藏、锁定、复制、删除；快捷键支持撤销、重做和方向键微调。
5. 顶部预览可修改模拟心率、电量、步数、时间和秒数，观察阈值颜色变化。
6. 项目自动保存在 IndexedDB，可导出 JSON 备份并导入为新的项目副本。导入不沿用原代码和签名身份，需要重新生成代码。
7. 模型设置填写 Chat Completions 兼容服务地址和模型 ID；Key 默认仅会话保存，主动勾选后才持久化。
8. 可以测试连接、获取模型列表、保存多份配置与切换默认配置。
9. 编辑器 AI 抽屉输入需求并生成，浏览器将设计 JSON 和资源清单发送给用户配置的模型；审阅后应用代码。
10. 编译按钮会检查 `/api/capabilities`。未接入后端时明确提示未连接，不生成虚假 PRG 或成功状态。

项目导出不包含模型配置。模型 Key 只作为浏览器请求的认证头，不传给编译服务。

## 内置 ClownWatch 参考项目

项目页固定提供 ClownWatch 参考项目，不可删除或覆盖。点击封面会创建独立的可编辑副本，使用新的项目 ID 和 Garmin 应用 ID，原始参考项目保持不变。副本包含完整 Monkey C 源码、设置资源和背景，可直接编译；修改画布后需重新生成代码。

网页采用分层近似预览；字体、舌头渐变、图标及符文细节以原生表盘为准。源码中的心率、电量阈值、12 个符文秒环和数据配置保留在构建工程中。

在相邻 WatchFace/ClownWatch 更新后，可在仓库内手动执行 `node scripts/sync-clownwatch.mjs` 重新生成参考包，然后构建并部署。服务器直接使用已生成的 `frontend/public/templates/clownwatch.json`，不依赖其他表盘项目目录。

## SkyRing 与 fine-o-clock 默认参考

项目页还提供不可删除的 SkyRing、fine-o-clock，使用时创建独立应用 ID 的可编辑副本，包含源码、图片、位图字体及配置资源。SkyRing 使用独立的时间、数据、外圈和图表图层；fine-o-clock 以场景静帧叠加时间和数据作为近似预览，网页不执行 Monkey C 动画。原生源码与动画资源仍随副本保留。

运行 `node scripts/sync-reference-projects.mjs` 可从相邻 WatchFace 工作区中的原生项目刷新这两个参考包。fine-o-clock 的设备专用资源合并到参考包的 resources，并修正 Linux 字体引用大小写；不会修改原项目。素材继续按当前规则保存在浏览器，编译时随工程上传。

## 创建时选择系列、型号与尺寸

新建表盘或空白项目时，输入名称后按“系列 → 型号 → 尺寸”选择设备。当前提供 Venu 4（41/45mm）、Venu 3（45mm）、Venu 3S（41mm）、Forerunner 570（42/47mm）、Forerunner 970（47mm）、fēnix 8 AMOLED（43/47/51mm）。型号与分辨率依据 https://developer.garmin.com/connect-iq/compatible-devices/ ，不代表销量排名。

屏幕分别为 390、416 或 454 像素。项目保存设备 ID 与表壳尺寸，导出/导入后保留；未记录目标的旧项目默认为 Venu 4 45mm。编辑器保持 454×454 的统一设计坐标，模型收到目标 ID 和按实际 Dc 尺寸缩放的要求。生成代码是否完全正确仍需审阅和设备验证。

后端按所选设备校验 manifest、执行 SDK 编译，并在任务中持久化目标。fēnix 8 AMOLED 的 47mm 与 51mm 共用 Garmin SDK 设备 ID fenix847mm，项目仍分别保存表壳尺寸。内置参考项目保持原来的 Venu 4 45mm，不自动宣称适配其他设备。

多设备编译回归：`node backend/tests/devices.mjs`。

## 独立预览窗口

编辑器顶部点击“预览”，进入独立窗口，不显示选框或编辑工具。默认并排显示亮屏与息屏，也可切换为单独显示。

- 播放/暂停、1×/2×/4×速度、秒数拖动与归零；模拟时钟跨分钟连续推进，关闭窗口停止计时。
- 日常、运动、低电量和数据缺失四种场景；可以手动调整时间、心率、步数及电量。阈值颜色作用于配置了阈值的绑定数据图层；静态参考图片不会随数据改变。
- 适应窗口、实际像素及 200% 查看。实际像素以目标设备的 390/416/454 像素为显示直径，受浏览器缩放和操作系统显示缩放影响，不表示物理毫米大小。
- 可打开边界辅助线；息屏仅显示标记为息屏可见的图层，并非 SDK 功耗或烧屏验证。
- 按 Escape 或点击关闭退出，回到原编辑状态。预览只维护模拟数据，不修改图层、代码或设计版本。

当前网页仍基于 SVG 图层预览，不执行 Monkey C；旧副本中的整图参考、fine-o-clock 静帧及 ClownWatch 近似图层不会自动成为原生动画。原生字体、复杂绘制、动画与实际息屏效果仍需模拟器和真机验证。

本次远程验证：编辑/拖动/撤销回归与独立预览两项测试通过，包括播放暂停、秒数归零、场景颜色、缺失数据、390 像素视图、息屏筛选、Escape 退出和设计版本保持。

实时模拟默认开启：打开独立预览时读取浏览器当前本地时间和日期，心率每秒随机生成 50–160 的整数，步数从 4500 开始每秒增加 1–5。暂停时所有动态数据停止，继续时钟同步当前时间。关闭后停止更新，重新打开步数重新从 4500 开始。选择场景、归零或手动调整时转为暂停的手动模式；可勾选“实时模拟”恢复。实时模式固定每秒更新，倍速仅用于手动模拟时钟。

## 服务商与模型预设

模型配置增加 DeepSeek、OpenAI、Google Gemini、阿里云百炼（北京）、OpenRouter、Mistral、Ollama 和自定义兼容接口。选择服务商自动填入 Base URL 与默认模型，预设模型可直接选择，也可获取账号实时列表或填写自定义 ID。切换服务商清空旧密钥，防止密钥误发至另一服务。现有配置不自动覆盖。

预设只列出文本代码生成模型，不列入 GPT Image 等图片模型；Anthropic 原生协议尚未接入，可通过用户有权限的 OpenRouter 路由选择 Claude。预设不代表账号权限或所有服务已实测，浏览器直连还需服务商允许 CORS。

本地专用浏览器使用 `%LOCALAPPDATA%/GarminFaceCreator/Browser` 配置目录。双击根目录 `Open-Configured-Browser.bat` 可打开该配置的 Edge（需要当前开发依赖）。它访问远程页面，不启动本机服务；与用户日常浏览器配置独立，密钥不进入项目、镜像或服务器。`deploy/tools/test-deepseek-local.mjs` 从进程环境读取测试 Key，执行真实连接、生成和编译测试，不内置凭据。

## PRG 文件名

新构建的产物和下载名称统一为 `{型号}_{尺寸}_{项目名称}.prg`，并移除全部空白字符。例如 `Venu4_45mm_ClownWatch.prg`、`Forerunner570_42mm_运动表盘.prg`。中文保留；Windows 文件名不允许的字符替换为下划线。fēnix 8 的 47/51mm 虽共用设备 ID，仍按项目选择的尺寸命名。

构建记录保留构建时的项目名称和尺寸，之后重命名项目不会改变已有产物名称。旧构建仍可下载；未记录项目名称的历史任务使用 WatchFace 作为回退名称。文件下载接口保持兼容，页面显示实际文件名。

已验证 Venu4 45mm 命名、fēnix 8 51mm 中文及非法字符处理、旧产物下载与页面编译下载回归。

## 模型请求中的完整设备参数

生成请求新增 `design.device`：series、model、size、target、screenWidth、screenHeight、screenShape（round）、screenTechnology（AMOLED）。型号名称、表壳尺寸和实际像素分辨率均由本地设备目录解析，不由用户随意填写。顶层 target、deviceSize 与 requiredManifest 的 product 使用同一个解析结果。

`design.designCoordinateSystem` 明确 width/height=454、origin=top-left、units=designUnits、scaleToDevice=true，并给出实际分辨率与设计坐标之间的 scaleX/scaleY。系统提示要求区分毫米和像素，以运行时 Dc 宽高作为绘制依据，按实际屏幕计算中心、圆形边界并缩放坐标、字体和线宽。

旧项目缺少设备字段时补为 Venu 4 45mm；不合法的型号/尺寸组合在调用模型前拒绝。fēnix 8 的 47/51mm 虽共用 SDK target，仍保留各自的 size。

验证覆盖：旧项目默认值、390/416/454 像素、fēnix 51mm、manifest 一致性、图片二进制和 Key 不进入提示词、非法设备不触发模型调用。测试使用模拟模型响应，不产生付费模型调用。


## SkyRing 分层参考项目

SkyRing 默认参考包已改为 159 个独立图层，不使用整张原生截图：背景、天光外圈、方位刻度、太阳/月亮标记、时间日期、日出日落说明、心率/压力/恢复/活动/天气数据、折线与柱条等。数据控件可以改位置、尺寸、颜色与绑定；线段增加 1–32 的线宽选项。

时间、心率、步数、电量等使用现有动态预览；压力、恢复、天气等当前使用示例值，天文外圈与历史图表也是近似示例，网页不执行原生天文与历史统计逻辑。完整 Monkey C 源码、字体和资源保留，未改画布时仍可直接编译。

刷新页面并重新点击“使用 SkyRing”创建副本即可获得分层版本。已有个人副本不自动覆盖。编辑图层后仍按原有规则使代码过期，需要重新生成代码才能让布局改动进入 PRG。


独立仓库位置：`<project-directory>`。原生参考表盘位于相邻的 `<reference-project-directory>` 工作区；只有手动刷新参考包的脚本依赖该目录，正常构建、使用和服务器部署不依赖原工作区。


## 可靠性与设计能力更新

- 保存使用独立 storageVersion 原子校验，两个页面编辑同一项目发生冲突时保留内存设计，可加载最新、另存副本或放弃保存；配额/事务失败提供导出与重试入口。
- schema v1–v4 顺序迁移；未来未知版本拒绝。图片 assetId 独立于图层，复制/导入保持引用，编译仅上传去重资源。含代码/历史的 JSON 导入先确认丢弃范围，可取消。
- 属性输入合并为一步撤销；多选支持批量锁定/复制/删除和基础对齐，锁定图层受保护。属性面板只编辑主选图层。
- 文字可设置对齐、字重和 Garmin 字体映射；指标支持标签、单位、小数位及缺失值；边界提示按旋转和网页文字宽度估算，可定位，装饰可允许裁切。
- 圆环可配置刻度、起止角、线宽、暗色透明度和数据目标；阈值编辑需应用，区间不能重叠，数据缺失和未命中使用兜底色。
- 息屏独立颜色、字号与秒数策略；秒数隐藏或固定 00，圆环停止按秒点亮。网页检查不等于真实功耗/防烧屏验证。
- AI 抽屉独立选择本次模型，不重排默认配置。参数按模型能力/协议处理，可显式覆盖；非敏感草稿自动缓存，Key 仍依赖手动保存的会话/持久策略。
- 模型输出歧义、截断或路径错误时保留原文供查看/复制，不执行 HTML，不覆盖已应用工程。
- 增量日志保留原文并标注错误/警告；可定位源码行，网络中断后继续观察原任务；任务过期按 API 状态说明。
- 历史区分设计与代码快照，支持固定与恢复；恢复设计使代码过期。数量/空间超限时优先回收旧未固定版本，不能回收受保护内容时拒绝保存。
- 源码 ZIP 导出见 [源码导出说明](source-export.md)，保留实际来源和适用声明；原作许可未核实时不宣称授权完备。

设备与隐私检查见 [设备自测清单](device-self-test.md)，完整实施证据见 [阶段验证](stage-validation.md)。

图片独立存储与迁移/共享引用规则见 [浏览器素材存储](asset-storage.md)。旧页面遇到数据库版本提示时，先导出未保存设计，再关闭旧页面并刷新；不要通过清空数据库处理。

图层支持平面分组、折叠、重命名、缩略图及按名称整理。分组不改变绝对坐标和原生绘制顺序，组头可一次选中所有成员；基础配色按范围批量替换，保留独立阈值/AOD 颜色。

坐标锚点支持中心及四角读数，存储仍为左上角；眼睛图标控制编辑器显隐，原生导出开关控制独立预览与输出。辅助线默认不导出，其专用图片也不进入编译清单；旧隐藏图层迁移时保留为不导出。

形状支持填充、描边、圆角及透明度，已核查当前设备目录的增强图形能力；原生 API 映射与色深差异见 [图形能力表](graphics-capabilities.md)。

创建项目可选择初始布局、安全边距和字体建议，说明见 [设备布局模板](layout-presets.md)。
