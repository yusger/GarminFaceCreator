# 设备布局与安全指导

创建项目时先选系列/型号/表壳尺寸，再选基础数字、大字时间、运动数据或空白布局。提供当前 390/416/454 像素目录的安全边距与字号建议，保持统一 454×454 设计坐标，不把表壳毫米值用作像素尺寸。

安全边距以实际设备像素记录，默认约屏幕直径的 4.5%，可设 0–40px；创建时按比例收拢主要内容，装饰圆环可以靠近屏幕边缘。字体指导为正文至少约 14px、时间数字约 64px，属于设计建议，不替代真实 Garmin 字体与语言字形检查。

编辑器安全圈与预览辅助圈是指导层，不进入原生代码。安全圈显示开关不改原生版本，设计快照保留布局指导和目标。内置原生参考工程仍按既有目标使用，不因选择其他模板就宣称跨设备适配。

设备扩充须先核对官方 SDK ID、尺寸、分辨率、设备包、增强图形/alpha 能力及真实编译，再加入设备目录和回归；不能凭型号名称猜 SDK target。当前布局阶段使用已核查的目录，不对未核查的新设备作支持声明。
