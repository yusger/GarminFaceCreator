# 分阶段实施与验证

每阶段流程：实现及本地构建 → 实现提交 → 指定远程测试环境部署和验证 → 结果提交 → 下一阶段。测试地址和凭据不写入仓库；Temp 继续仅用于本地临时资料。

## 阶段 1：P0-01 保存与冲突恢复

- 实现提交：`7abad50`。
- IndexedDB 在同一个读写事务内比较并递增 storageVersion，与设计 revision 独立；旧项目缺失版本按 0 处理。
- 保存任务串行执行，失败停止自动写入；当前内存设计、导出入口及关闭页面提醒保留。
- 冲突可加载最新、另存独立副本或放弃本次保存；加载前确认，副本需重新生成原生代码，避免沿用旧应用 ID。
- 不依赖 BroadcastChannel，关闭该功能仍保护冲突。存储打开、blocked、事务中止与配额失败均有错误出口。
- 本地：TypeScript/Vite 生产构建通过。
- 远程：已提交产物部署后，`storage.spec.ts` 2 项通过，现有 editor 编辑/撤销/预览/保存/导出回归 1 项通过。
- 浏览器测试使用独立测试上下文，不改写用户浏览器中的项目，不调用付费模型。

- 隔离脚本首次检查遇到启动时连接重置，补就绪重试后通过；脚本见 backend/tests/readiness-isolated.sh（从测试部署目录运行）。

## 阶段 3：P0-03 图片资源链路

- 实现提交：`b8375be`，远程复现后的修复提交：`c289dc6`。
- 修复导入副本沿用 storageVersion 导致误报冲突；副本版本重置为 0，仍生成独立项目/应用身份。
- 网页中文、空格和符号素材名称保留为图层名称，实际图片资源使用 UUID 路径。多图导出/再导入后，生成请求仅含素材路径、不含图片二进制；生成资源 XML、上传路径和源码引用一致。
- 远程实际发现 SDK 无法解析中文 PNG 工程路径（文件已正确上传），因此原生工程非 ASCII 路径在 API 排队前明确拒绝。兼容现有网页自动生成的 ASCII 素材路径，不盲目搬迁已有资源目录。
- 远程多张 PNG + 位图字体真实编译/PRG 下载通过；中文原生路径拒绝场景通过。
- 本机 SDK 模拟器加载远程产物，确认红/蓝两张位图及白色位图字体测试字形实际显示，截图见 [资源验证](screenshots/resource-validation.png)。模拟器已关闭；未据此声称完成真机验收。
- 最终远程浏览器回归 6 项通过：ClownWatch、SkyRing、fine-o-clock 独立参考副本真实编译，图片导出再导入/编译，原子保存冲突，配额失败重试。

- 实现提交：`23740fd`。
- 拖拽保存起点与独立最新图层，pointerup 使用最终位置；拖拽期间暂停自动保存，结束只提交一次 revision/历史。
- pointercancel、丢失捕获及 Escape 回滚；零位移不增加历史或清空重做，结束后恢复未完成保存。

## 阶段 5：P1-02 AI 失败恢复与安全解析

- 实现提交：`f3cb88e`。
- 先严格解析完整 JSON；兼容说明文字中的唯一、完整 JSON 围栏；歧义、截断、语法及路径错误均拒绝，不截取首尾大括号拼接结果。
- 文件路径继续校验，补大小写重复和源文件缺失检查。
- 截断/解析错误保留类型化失败原文和原因，以只读文本显示，可复制、手动选择或清除，不自动上传编译服务。
- 失败不会改写已应用的工程或画布；跨项目清除失败展示，模型返回 HTML 不作为页面执行。
- 本地生产构建通过；远程关联测试 8 项通过，包括解析边界、失败原文显示、截断保留、既有机型参数与无效设备拒绝。

## 阶段 6：P1-03 模型选择与参数兼容

- 实现提交：`453ce1d`。
- AI 面板可独立选择本次生成模型，不调整设置中的默认配置顺序。
- 生成和连接测试共用参数构造；按接口协议选择 Token 字段，按已获取的 supported_parameters、推理模型家族和 DeepSeek 思考开关处理温度，提供显式参数覆盖以兼容自定义网关。
- 模型列表接口保存各模型参数能力；不因提供商不是 OpenAI 就统一禁用温度。
- 非敏感设置草稿自动缓存，不保存草稿 Key；切换档案使用各自密钥并重新隐藏输入，修改服务地址清除不适用 Key；重开草稿仅从同 ID/地址/服务商的已保存档案恢复密钥。
- 本地生产构建通过；远程关联测试 11 项通过：本次选择不改默认、A/B 会话与持久 Key 隔离、地址变更清空、草稿无密钥、参数协议与已有生成/设备回归。全部使用模拟模型响应，无付费 API 调用。
- 参数依据：[OpenRouter 模型能力接口](https://openrouter.ai/docs/api/api-reference/models/get-models)、[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。预设与启发式不代表所有网关均支持，必要时使用显式覆盖和连接测试。

## 阶段 7：P1-04 增量编译日志与任务观察

- 实现提交：`8e6ec89`。
- 前端按 /logs?after= 游标读取并校验增量，保留已读取原文；服务端游标越界时显式 reset 并返回完整缓冲。
- 网络中断最多连续重试三次，随后保留任务 ID/日志；继续观察复用原任务，不重新上传或排队。
- 先读取任务状态再获取日志，终态包含最终输出；成功、失败、取消与重启中断均结束观察。
- 原始日志按行高亮警告/错误，文件位置可跳转到本次编译使用的已应用工程，标记行号，不覆盖未应用的 AI 审阅结果。
- 本地前端/.NET 构建通过；远程大日志/续看/重置/源码定位测试 2 项通过，真实 SDK 编译与下载、失效游标重置、失败与取消 API 回归通过。

## 阶段 8：P1-05 任务与历史保留

- 实现提交：`a69cbc5`。
- 后端工程/PRG/日志/任务记录分别按 48/168/168/720 小时保留，终态记录上限 200，最短诊断窗口 24 小时；均可通过环境变量调整。仅回收满足独立期限的最旧终态，保护仍在保留期内的记录，数量上限因此可能暂时超过。
- 工作线程运行标记和产物下载租约阻止清理正在使用的任务；路径必须位于任务根目录，拒绝异常 ID/链接目录，不清理 SDK 或签名密钥。
- 重启中断任务从当前时间开始保留；API 标记工程/产物/日志过期，前端提示重新编译或日志已过期。
- 浏览器每项目代码快照上限 20 个/10MB，清理优先最旧未固定版本，保护当前代码和固定版本；受保护内容已超限则拒绝保存，内存设计保留，可导出、手动清理和重试。
- 本地前端/.NET 构建通过；远程历史/保存/日志关联检查 6 项及真实编译/下载/失败/取消通过。
- 远程临时容器使用合成历史任务验证独立组件过期、数量回收、近期任务和重启中断保护，通过后停止并删除测试目录，未挂载正式任务或签名密钥。

## 阶段 9：P1-06 导入、迁移与设计快照

- 实现提交：`83db2f9`；补持久项目读取迁移提交：`05fd756`。

- 图片以稳定 assetId 定位，复制图层和导入副本不改写素材身份；相同路径相同数据上传去重，不同数据冲突明确拒绝。
- 含代码或历史的 JSON 导入前说明仅恢复当前画布，代码、代码快照及设计快照不恢复；可取消且不改写原项目。仍不声称支持 ZIP 导入。

- 设计历史与图片二进制均不进入模型请求；生成只发送素材引用清单。
- 本地构建通过；首轮关联测试 13 项通过，补充持久旧版本/未来版本检查后的 10 项通过；三个默认参考副本真实编译通过，图片导出/导入/位图字体编译通过。
- 图片回归首次在创建项目事务完成前操作全局隐藏文件输入，补“已保存”就绪等待后通过；该变更只修复测试同步，不放宽断言。
