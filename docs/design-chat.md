# AI 设计助手

编辑器顶部点击“AI 设计助手”，在右侧面板选择已有模型，用自然语言描述创建或调整要求。发送当前设计结构、目标型号/实际像素、选中层、数据目录、可用内置控件及最近12条对话；模型密钥复用浏览器本地配置，不进入设计请求正文。图片像素、素材文件、工程源码及许可全文不自动发送。

有效回复校验后整轮自动应用，并显示程序生成的改动摘要。支持基础图层添加/删除、位置字号配色、数据绑定与阈值、背景色、内置复合控件添加、已有配置参数和内部部件显隐。复合控件始终是一个顶层对象，不能通过回复替换内部结构；新增控件 ID 由程序分配，后续轮次才能引用。

锁定图层须先手动解锁。多设备项目先切换共享主设计；单设备布局使用原有设备适配助手。现有图片保留，但本版不支持对话上传/生成位图、任意素材安装或模型修改原生工程。特殊扫描/动画可以写入原生效果说明，网页预览能力与后续生成工程仍分开。

一轮修改形成一次编辑撤销记录，画布工具栏提供撤销/重做；面板的“撤销上次编辑”撤销最近一次编辑，若期间手动操作，会先撤销该操作。背景色、图层及配置一并恢复。清空对话不撤销设计；收起面板保留本次对话，切换项目/离开编辑页/刷新后不保留聊天记录。当前设计始终优先于旧对话，包括手动编辑及撤销后的设计。

请求期间可取消；收起或离开面板会取消未完成请求。等待期间设计发生变化时拒绝应用迟到结果，用户重新发送即可。没有自动重试；无效字段、未支持操作、锁定目标或无效几何导致整轮拒绝。输入保留供修改重试。讨论型回答允许无操作，不产生编辑记录。

对话调整只修改设计，不生成 Monkey C，也不调用后端编译。满意后再使用“AI 生成代码”或可用的本地生成；已有代码保留但标记过期。发送会调用所选模型，可能产生服务商费用。
