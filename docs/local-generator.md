# 浏览器本地生成试点 basic-1

从空白项目开始，使用 ASCII 项目名和文字，加入时间、文字、矩形、椭圆或直线，点击「本地生成（试验）」，审阅并应用后编译。这个入口不请求大模型，不需要 Key；后端仍只校验和编译。

边界：目前只支持未旋转的上述五类组件。图片、日期、数据、圆环以及非 ASCII 字形尚未验证，包含这些内容会明确拒绝生成，不悄悄丢弃；可暂时关闭相关层的原生包含开关，或继续使用 AI 模式。

坐标按目标运行时宽度缩放 454 方形设计空间；当前设备目录均为方形像素的圆屏。矩形圆角/椭圆用固定多边形近似；支持填充、描边、透明度、对齐、原生字体选择和独立 AOD 显隐/配色。原生系统字体字号是离散映射，浏览器字重/间距不能逐像素复制，需设备检查。不包含 SDK 字体，不声称符合所有 AMOLED 息屏像素限制或已测量功耗。

schema v9 为项目和代码快照记录唯一主生成来源 ai/deterministic/reference/unknown，并记录本地生成器版本。旧工程来源保留 unknown，不猜测为 AI。已有代码在首次替换前补存快照；切换主来源应用时需要确认，取消保留原代码。恢复代码同时恢复来源。未来 AI 修复/手动修改必须记录 patches，不能继续冒充未经修改的确定性输出。

AI 和本地生成共用互斥入口与代码审阅流程；设计版本变化则拒绝应用旧结果。源码包元数据记录生成来源。此阶段是范围验证，不替换已有原生参考工程，也不扩张为完整编译器。

后续 basic-2-icons 扩展：增加受控内置图标与 Monochrome 缓存天气绑定，固定资源/辅助代码由前端生成，详见 [素材库](icon-library.md)。原版 basic-1 的代码快照仍保留其版本标识，不自动重写。
