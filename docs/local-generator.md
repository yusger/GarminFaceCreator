# 浏览器本地生成试点

当前版本 **basic-5-data**：支持未旋转的时间（完整/小时/分钟）、日期、ASCII 文字、基础形状、步数/电量目标仪表、受控内置图标和步数/电量/秒数/当日总热量/当日距离。其他数据、圆环、任意上传图片和非 ASCII 字形仍明确拒绝本地生成，可继续使用 AI 方案。后续段落保留各阶段扩展记录。

## 初始 basic-1 范围

从空白项目开始，使用 ASCII 项目名和文字，加入时间、文字、矩形、椭圆或直线，点击「本地生成（试验）」，审阅并应用后编译。这个入口不请求大模型，不需要 Key；后端仍只校验和编译。

边界：目前只支持未旋转的上述五类组件。图片、日期、数据、圆环以及非 ASCII 字形尚未验证，包含这些内容会明确拒绝生成，不悄悄丢弃；可暂时关闭相关层的原生包含开关，或继续使用 AI 模式。

坐标按目标运行时宽度缩放 454 方形设计空间；当前设备目录均为方形像素的圆屏。矩形圆角/椭圆用固定多边形近似；支持填充、描边、透明度、对齐、原生字体选择和独立 AOD 显隐/配色。原生系统字体字号是离散映射，浏览器字重/间距不能逐像素复制，需设备检查。不包含 SDK 字体，不声称符合所有 AMOLED 息屏像素限制或已测量功耗。

schema v9 为项目和代码快照记录唯一主生成来源 ai/deterministic/reference/unknown，并记录本地生成器版本。旧工程来源保留 unknown，不猜测为 AI。已有代码在首次替换前补存快照；切换主来源应用时需要确认，取消保留原代码。恢复代码同时恢复来源。未来 AI 修复/手动修改必须记录 patches，不能继续冒充未经修改的确定性输出。

AI 和本地生成共用互斥入口与代码审阅流程；设计版本变化则拒绝应用旧结果。源码包元数据记录生成来源。此阶段是范围验证，不替换已有原生参考工程，也不扩张为完整编译器。

后续 basic-2-icons 扩展：增加受控内置图标与 Monochrome 缓存天气绑定，固定资源/辅助代码由前端生成，详见 [素材库](icon-library.md)。原版 basic-1 的代码快照仍保留其版本标识，不自动重写。

阶段 32（basic-3-time-parts）：时间控件支持完整 HH:MM、独立 HH、独立 MM；读取同一帧设备本地 24 小时时间并补零，网页预览与原生遵守相同分段。每层可独立布局与配色；Garmin 系统字体不保证复现浏览器字重。schema v12 为旧项目和设计快照补 full 默认值，不改写历史代码。

阶段 33（basic-4-meters / schema v13）：增加步数、电量分段目标仪表，支持水平直条和左右弧形。每个仪表是一层，目标/分段数/暗部/颜色独立配置；更换形状应用推荐尺寸与位置，之后仍可拖动缩放。网页与原生共用多边形采样，弧形从下向上点亮，直条从左向右点亮；按完整分段取整，超过目标封顶，缺失/非法值全暗。目标为固定设计值，不跟踪设备自动目标。步数与电量原生读取每帧各至多一次，捕获缺失或异常；AOD 按图层包含和配色绘制，不开动画计时器。真实设备的低亮可见性及功耗仍需实测。

读取依据：[ActivityMonitor.Info.steps](https://developer.garmin.com/connect-iq/api-docs/Toybox/ActivityMonitor/Info.html) 为当日步数且须检查空值，[System.Stats.battery](https://developer.garmin.com/connect-iq/api-docs/Toybox/System/Stats.html) 为百分比。首版不扩到其他目标源。

阶段 34（basic-5-data）：日期为设备本地英文星期缩写 + 当月日号；真实 ActivityMonitor 提供当日步数、总热量（不是运动热量）和厘米距离（转公里），System 提供电量与秒数。数据每帧集中读取，缺失/异常/非法值显示自定义占位而不填模拟数值。支持标签、单位、小数位、步数千分位、阈值与兜底颜色；自动数值最多六位小数并去尾零，显式小数位保留尾零，浏览器格式同步。息屏秒数按隐藏或固定 00，无秒动画；息屏颜色优先于阈值。

日期与格式依据：[Gregorian.Info](https://developer.garmin.com/connect-iq/api-docs/Toybox/Time/Gregorian/Info.html)、[Float.format](https://developer.garmin.com/connect-iq/api-docs/Toybox/Lang/Float.html)。数值仍受设备浮点精度限制；标签改成别的单位不会自动改变数值。

阶段 36（basic-6-calendar / schema v14）：三周日历是一层可编辑控件，7 列、标题加三周共四行，周一起始或周日起始，显示前一周/本周/后一周。今日反色、跨月暗色和星期标题可独立配置。网页预览增加日期选择，动态模式读浏览器本地日期，手动模拟跨午夜同步日期；编辑器静态示例日期为 2026-11-23，与原有 MON 23 一致。

原生日历读 [Gregorian.info](https://developer.garmin.com/connect-iq/api-docs/Toybox/Time/Gregorian.html) 的设备本地日期，按年月日滚动处理跨月跨年和 Gregorian 闰年规则；不靠一天固定秒数跨 DST。单独缓存两种周起始网格，本地日期变化时重建。没有绑定秒计时器；AOD 仍按图层显隐/颜色。星期为两字母英文，不分发 SDK 字体。默认 FONT_XTINY，缩小控件后需原生检查字体是否容纳。
