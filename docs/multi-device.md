# 一个主设计与多个设备适配

项目仍共用名称、项目 ID、应用 ID 和主图层，设计坐标保持 454×454。基准设备是首次创建时选择的设备；添加适配设备不会复制成另一个项目。当前目录限圆形 AMOLED，不宣称其他屏幕或未验证的设备兼容。

打开顶部“适配设备”，启用后选择“共享主设计”或“当前设备微调”。主设计修改同步给所有设备；微调只保存位置、宽高、字号、旋转、颜色、描边、AOD 和显示开关的覆盖值。已覆盖的属性不会随主设计该属性改变；重置微调即可恢复跟随。添加/删除/重排图层、修改数据绑定和图片应在主设计进行。选择设备后预览沿用当前预览数据；实际分辨率、字体指导和编译资源按目标设备确定。

每个设备（SDK target + 表壳尺寸）分别保留原生源码、代码历史、设计修订及最后构建任务状态。相同 SDK target 的不同表壳尺寸在页面仍可分别管理。共享应用身份不意味着共享 PRG：每个目标需分别编译。新增设备无可编译代码；主设计更新使其他设备代码过期，设备微调只使当前设备代码过期。主设计模式存在微调时，先进入设备模式再生成/编译，防止漏用覆盖值。

“生成全部设备代码”使用现有本地生成器，不调用模型；所有目标均成功生成才一起应用，原代码按设备保留历史。不支持的设计会整体拒绝，不自动静默删除图层。AI 仍按所选设备生成；已有用户确认和代码审阅流程继续适用。“AI 辅助适配”可选调用当前模型：查看发送内容、明确请求、比较前后效果后应用。只接受已有未锁定图层的几何/配色/显示差异，拒绝绑定、图片、身份与源码变更；应用前保存完整设计快照，应用只影响当前设备并使其代码过期，可在历史中恢复适配前设计。请求不发送素材像素、源码、历史或其他设备配置；不自动请求、重试或编译，费用由所选服务商计费。取消或关闭助手会中止请求；结果失效或非法时保留原设计。

“编译全部设备”先检查所有目标代码一致，再顺序提交各自的真实 SDK 构建。一个设备失败不代表其他设备通过或失败；结果分别展示下载入口。取消当前任务仍只取消当前构建，队列会继续后续设备。构建状态只记录本次任务结果，不构成真机认证。

schema v20 保留旧单设备项目；打开或迁移不会自动新增设备、更改旧源码或调用 AI。设计 JSON 备份保留主图层与设备覆盖；导入重新分配项目/应用/图层 ID，保留适配设计并清空各设备源码、代码历史和构建状态，避免旧身份及源码混入。设计快照保存适配设计，恢复会使代码过期。浏览器素材存储遍历嵌套结构，因此主设计与历史素材仍受引用保护。

批量本地生成包含的是目标设备相应设计；目前不输出可直接上架的多产品 IQ 包，也不合并模型产生的多套 Monkey C。分别生成的设备工程是本阶段构建单位。
