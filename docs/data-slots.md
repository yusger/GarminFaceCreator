# 联动数据槽（阶段 A）

数据槽复用 ProjectControl 的 dataSource 类型，以 slot:true 显式标识，不建立第二套来源状态。一个稳定配置ID可以绑定数值、连续/分段进度条和进度环，标签继续通过sourceLabelFor引用数值。旧配置保持原行为；内部项目Schema32无损迁移31，旧外部交付包不因此获得新字段。

编辑器「表盘配置→创建联动数据槽」勾选相同初始来源的可编辑读数及进度控件。允许来源取控件能力交集，进度条仅步数/电量，进度环仅已支持来源。已有来源绑定、锁定读数不重复绑定。创建与设置可以撤销。

切换同步单位、精度、分组格式和设计目标；跨来源不沿用旧阈值，自定义默认阈值保留。sourceGoals按来源保存设计目标，不代表Garmin个性化目标；preserveFormatFor为明确保留格式的成员列表。当前原生字形/来源限制继续由生成诊断检查全部选项，不能仅当前选项可用就认为配置完整。

原生生成编译所有来源分支，使用同一个SDK数据读取契约。历史图表、图标自动替换和多主题尚属后续阶段；目前静态图标仍走已有显式联动，不宣称已支持任意数据图标。配置导出仍包含在项目里，应用原生配置的实际入口由后续手表设置阶段接通。
