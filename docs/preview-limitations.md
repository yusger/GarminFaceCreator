# 网页预览与手表验证

网页预览是设计检查工具。编译通过表示 SDK 接受工程，不代表网页与真机逐像素一致，也不代表功耗已经测试。

| 项目 | 网页行为 | 原生验证方式 |
| --- | --- | --- |
| 数据 | 当前时间来自浏览器；心率随机 50–160，步数从 4500 累加；其他字段为样例/场景值 | 模拟器注入数据，真机核对 API、权限、缺失值与单位 |
| 字体与文字 | 浏览器字体，系统可能自动补字；粗细和尺寸仅近似 | 指定目标、设备语言和实际 Garmin 字体，检查中文/符号、长读数及截断 |
| 图形与颜色 | SVG、桌面屏幕色彩和抗锯齿 | 核对目标分辨率、色深、透明混合与圆屏边缘 |
| 动画与秒数 | 浏览器定时器，暂停/加速只供场景检查 | 检查 WatchFace 高低功耗生命周期及实际刷新限制 |
| 息屏 AOD | 展示 aod 标记与配色/字号/秒数策略 | 检查设备息屏限制、可读性和恢复亮屏；网页不模拟系统全部保护策略 |
| 电量与功耗 | 电量字段可模拟，未提供耗电估算 | 在同一真机、亮度与使用条件下测量；记录时长、开始/结束电量和基线 |
| 参考工程 | 部分原生动画或资源仅以近似图层展示 | 编译原生工程并运行，不把截图当作已经实现的原生效果 |

建议依次检查 390/416/454 像素目标、亮屏/息屏、无数据、长文本与边界。未适配的型号不能仅靠缩放就宣称兼容。

提交问题时使用仓库 Bug 模板，注明网页/模拟器/真机、版本、设备、SDK、步骤、预期与实际。截图和日志需移除 API Key、密码、私网部署信息及个人健康数据。无需导出完整浏览器存储；素材和项目备份应先检查内容。

实测记录见 [设备自测清单](device-self-test.md)，逐阶段结果见 [阶段验证](stage-validation.md)。本文不提供未经测量的功耗数字。
