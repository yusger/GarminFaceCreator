# Rider原稿可编辑还原验证

维护脚本scripts/create-rider-validation-fixtures.mjs显式接收原稿目录，只将02装甲/05管线的双尺寸工程和审计写入本地Temp/rider-validation，不注册默认库、不发布。输入限制为已审计的454 SVG简单形状子集，未知/主动/外部属性拒绝；多边形必须真正可表达，线端点变换逐一校验，不改成圆形。

原始数值绑定实时心率/步数/电量/总热量和设备时间；02原有装甲指针轮廓保留为动态handShape，05保留四条梯形管线与中央双八边形。有字距的静态标签保持一个文字复合对象，内部按原桌面字体推进量与原字距布置字符；不能把这些可编辑结构换成整张截图。

字体使用现有许可Share Tech Mono/Barlow常规400替代未提供字节的Consolas/Menlo 700，字号取整、字形/字重和SVG crispEdges与原生取整/圆形采样差异明确记录。参考的系统字体只在本地桌面测量/原图栅格化，不复制字体字节。源注释“10:24”与02实际305/60/60度静态指针不一致；正常实时时钟秒插值会造成约1度差异，不能假称完全同一固定时刻。

可选Playwright验证显式使用GFC_RIDER_FIXTURES/GFC_RIDER_SOURCE，检查可编辑结构、实际网页导出及真正SDK编译；原图/导出/工程只保留本地Temp，不提交。图像语义与差异由原稿及独立证据评估，不以Schema或编译成功当还原完成。Rider不进入默认表盘库。

为满足纯盘面截图契约，browser-capture-2移除exact模式的编辑器外缘描边，并将裁切半径与逻辑屏幕227对齐；编辑器辅助边框保持原用法。旧browser-capture-1记录是历史证据，不能覆盖或冒充新版基准。

固定数据比较使用scripts/compile-rider-fixed-fixtures.mjs，默认仅准备本地源码，显式--compile和GFC_TEST_URL才向测试环境提交。它保留真实网页准备的FNT/PNG，只对测试源码注入固定时钟/数据与帧完成标记；PRG与摘要留Temp，凭证只在内存。aod是强制同一绘制分支，未验证SDK睡眠事件或低功耗行为，不可作为普通动态表盘发布。


2026-11-27验证结果：02保留58个顶层对象/74个可编辑部件，05保留76个/97个；各自454/390亮屏和强制AOD分支共8张SDK原生纯盘面截图已在113独立隔离容器取得。动态工程4个与固定数据工程8个真实编译成功；绘制批处理后相关11项回归通过。固定工程不能作为真实时间发布。

scripts/compare-rider-fixtures.mjs将原稿本地栅格图、网页导出、SDK截图并排输出至Temp/rider-validation，并记录RGB绝对误差和单通道差值大于16的像素数。这些是描述性指标，黑色背景影响全图均值，不设置“误差小即还原通过”的门槛。人工检查确认多边形、梯形、装甲与管线仍保留，细线取整及字体显著不同；原稿Consolas 700、替代资源字体400和原生小字笔画问题分开追踪，未宣称视觉验收完成。

隔离条件：1CPU、768MiB内存上限、128PID、110秒软期限、无网络/新增权限/可写根目录，仅只读SDK/设备/字体和单PRG输入。8次独立运行均取得完成标记、目标像素截图并清理自身容器。docker stats每次9个采样，最高约160.2MiB，其他约134.7–141.2MiB；这是整个GUI/Java容器采样，排除部分缓存且不是精确峰值，更不是表盘运行内存或真机功耗。

大场景固定数据注入曾触发SDK Invalid jump offset。basic-35-batched-draw按4段绘制拆分方法，保留每层源映射、顺序与单帧数据快照；不能据此宣称任意大工程无预算限制。
