# 时间绑定指针

“指针”控件支持设备本地时针、分针、秒针，颜色、线宽、转动中心、长度与针尾可独立配置。时针包含分秒进度，分针包含秒进度；亮屏跟随系统表盘更新，没有新增计时器或常驻传感器。

转动中心 X/Y 为控件宽高的 0–1 比例。安全半径取转动中心到最近边缘的距离减去半线宽；长度和针尾均为这个半径的比例，因此边缘中心会缩短甚至变成零长度。拖动/缩放控件仍使用其固定外框；转动轨迹不会暗中改变选择框。零度指向 12 点，顺时针转动。网页和原生共用相同公式，原生按真实屏幕尺寸缩放；不使用 PNG 旋转帧。

切换为秒针时默认取消 AOD 显示。若显式保留，AOD 采用“固定 00”则停在 12 点，采用隐藏则不画；时针/分针在 AOD 也用秒数 0 计算，没有秒级动画。AOD 仍需用户在真实设备核查可见性、像素预算与功耗，未宣称烧屏保护认证。

本地生成试点仍拒绝非零“整体旋转”；转动中心控制的是动态时间转轴，不是该静态旋转字段。原生线条端点/抗锯齿和网页可能有像素差异。无效预览时间/秒数隐藏指针，不伪造时间。
