# AboutTime Creator adaptation

Source: https://github.com/samuelmr/garmin-abouttime
Pinned revision: `4fdf09bcf784ecf385b9dce546af3f277e13caa5` (master).
Thank you to **Samuel Rinnetmäki** and contributors for About Time and its translations.

This is a trimmed editable Creator adaptation initially for **Venu 4 45mm**, not an unmodified upstream release. The original MIT license, README and English/Simplified Chinese locale XML are retained. Original locale phrases retain MIT terms. The native program uses Creator GPL-3.0-or-later generator/adapter templates, whose applicable source context and full repository notice accompany exports; do not label the complete adaptation as independent MIT-only output.

## Included

- Three independently editable word-time row layers, live local date, battery, title, separator and background.
- The pinned English/Chinese phrases round to the nearest five minutes, including the 2:30 rounding boundary, hour/day transitions and Chinese noon/midnight expressions.
- Default rows use English, with independent layout/fonts/colors. Change all three rows to Chinese in their inspector to get a complete Chinese face; the selector recommends localized system font. Alternatively insert one complete three-line word-time component.
- Fixed native GfcWordTime helper is generated by the frontend and protected from AI override/repair. Native time uses the device clock, not the web preview sample. Default AOD keeps only the three gray word-time rows against black, with second=0 and no seconds animation.

## Differences and checks

- Uses Garmin system fonts, not upstream Noto/Andika or icon/font binaries. Chinese FONT_SYSTEM_XTINY was checked in the Venu simulator; font coverage on other devices and real hardware still needs checking. No SDK fonts are redistributed.
- English and Simplified Chinese only; no other language packages or original settings/indicator/fitness field infrastructure are copied. Per-row typography is configured in Creator, rather than automatically relocating emphasis to whichever row contains the hour as upstream does.
- Complete generated Monkey C and resources work with the fixed backend Jungle and were built with the current SDK; this does not require running upstream's SDK 9.4 build setup.
- No claim that upstream power figures, rendering strategies, AMOLED pixel budgets or burn-in behavior automatically apply to this adaptation.

## Rebuild

Set `GFC_ABOUTTIME_SOURCE` to the extracted pinned source text, run `node scripts/build-abouttime-reference.mjs`, then `npm run build`. Four upstream input hashes are checked. No upstream scripts are run and no font assets are read. Source export contains the actual complete native program, editable design, MIT original texts, full applicable notices and matching template source context when available.
